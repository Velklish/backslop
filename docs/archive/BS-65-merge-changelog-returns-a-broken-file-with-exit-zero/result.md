# BS-65 · Результат

**Закрыта 2026-09-22.** Выполнена. Закрыты четыре хода из пяти, названных в карточке; пятый («снять из шаблона `AGENTS.md` формулировку про единственный законный способ») не делался по решению владельца — он был условным, «пока это не сделано», а команда починена.

Корень дефекта: `splitSections` резала текст только по `^## `, а подгруппой считалась лишь жирная строка `**…**`. Заголовок `### Changed` для разбора записи был обычной строкой и уезжал в тело предыдущей записи — отсюда сразу оба симптома карточки: ложное предупреждение о расхождении тел при текстуально равных телах и дубль заголовка при сборке. Теперь `###` — граница записи; команда не выходит нулём при оставшихся метках конфликта, проверяет свой вывод тремя инвариантами и сохраняет позицию записи по конвенции «новое сверху».

**Проверки.** `node bin/backslop.js gates --require-clean --json` на `15a7ef8` — exit 0, «гейтов 2, зелёных 2»; `lint` код 0, `npm test` код 0, tests 294 / pass 294 / fail 0, дерево чисто. Против базы `1330e9e` (281 вердикт) снятых имён ноль, добавлено тринадцать. Мутационные пробы: якорь метки (`lib/merge-changelog.js:33`) — exit 1, покраснели два теста при одном ожидавшемся; счёт меток на выходе (`:416`) — exit 1; строка отчёта про снятый повтор (`:401`) — exit 1. Дерево чисто с обоих концов каждой.

**Три круга изолированного ревью, девять находок, из них две critical** — и обе нашлись только ревью, при зелёных гейтах. Первая: проверка метки конфликта искала **подстроку** по всему файлу, а в `CHANGELOG.md` самого backslop эта подстрока стоит прозой в код-спане с релиза v0.7.0 — команда отказывала бы на каждом слиянии в собственном репозитории. Вторая: тот же подстрочный счёт на выходе давал бы ложный ненулевой код. Дальше нашлось, что снятый повтор блока при `--base` исчезал из результата молча и с кодом 0, то есть свойство «+N / −0» ломалось без единой строки в stderr.

**Отдельно о методе.** Первая мутационная проба на якорь метки покрасила **ноль** тестов. Автор не переиграл её, а нашёл дыру в собственной фикстуре: упоминание метки стояло в выпущенной секции, где дефект гасит сужение до сливаемой секции, а не якорь. Тест на упоминание внутри сливаемой секции дописан, после него проба краснеет.

**Доки тем же ходом.** [ADR-024](../../adr/adr-024-changelog-merge-keeps-layout.md) — решение целиком, с двумя строками, разворачивающими Decision ADR-013 (позиция записи вместо «сначала ours», спор за одно место в пользу theirs); ADR-013 помечен `Superseded in part`; строка в таблице `docs/README.md`; `docs/reference/02-cli.md`; оба языковых слоя скилла `backslop-batch`, который эту команду и предписывает; `CHANGELOG.md`.

**Находка.** [BS-65.1](../../backlog/minor/BS-65.1-no-gate-catches-nonprintable-bytes-in-source.md) — непечатаемый байт в исходнике не краснит ни один гейт: `lint` и `npm test` были зелёными на файле, который `file` называл `data`, а `grep` не находил в нём слово, встречающееся трижды. Цена `minor`: ломается находимость, не поведение.
