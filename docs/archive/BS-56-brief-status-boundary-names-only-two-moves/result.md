# BS-56 · Результат

**Закрыта 2026-09-13.** Граница каталогов статуса в брифе объясняла только закрытие и перенос, и worker, встретив третий случай, правил карточку сам. Теперь брифы на обоих языках прямо закрепляют: текст файлов в `status` и `archive` правит approver, worker присылает формулировку.

**Ревью нашло в этой правке противоречие, и оно стоит записи.** Одна строка отдавала approver'у всю правку текста, а следующая велела worker'у **создать и наполнить** файл находки через `new --parent` — то есть ровно то поведение, которое сама карточка приводила как живой отказ. Обе нормы были повторены и в README. Закрыто явным выбором, а не умолчанием: запрет относится к правке **существующих** файлов статуса и архива и к переносам между ними; единственное исключение — создание новой находки отдельным файлом в ветке worker'а. Ревьюер подтвердил, что исключение не открывает дверь шире: команда выдаёт новый идентификатор и существующую карточку этим ходом не переписывает.

**Проверка.** Гейты на слитом дереве: `lint` код 0, `npm test` код 0 — 2 из 2. Мутационные пробы после коммитов: возврат старой формулировки в русский шаблон красит проверку границы (6 из 7); удаление исключения из русской копии красит её же. Обе восстановлены.
