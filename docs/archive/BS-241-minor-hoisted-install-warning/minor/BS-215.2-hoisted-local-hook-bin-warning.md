# BS-215.2 · Local install warning ignores a hoisted node_modules/.bin

- **Scope:** [02. CLI](../../../reference/02-cli.md#init)
- **Created:** 2026-10-03
- **Parent:** BS-215
- **Cost:** minor

## Evidence

Finding discovered while working on BS-215.

Evidence: Hypothesis: in a workspace with a hoisted parent node_modules/.bin/backslop, npx --no-install may resolve the command while hasLocalBackslop checks only the project-root node_modules/.bin; the init missing-install warning could therefore be false. No monorepo/workspace resolution was measured.

Confirmed 2026-10-06 on source 9c3c67078188f01dbdeff0fa4c185336c3ec2f0c by an independent refuter using a genuine npm 11.6.2 offline workspace install. Parent .bin/backslop and package symlinks targeted the exact source; npm ls exited 0, child npx --offline --no-install backslop version exited 0 (backslop 0.20.0), and the generated child Codex session-start hook exited 0. Child init exited 0 but incorrectly warned to run npm install. hasLocalBackslop was false and installedBackslopVersion null. Environment macOS arm64, Node 25.2.1, Git 2.54.0; no Windows execution claimed. Raw record: triage-refuter-evidence.json / BS-215.2-raw.json. Ordered into BS-241. The earlier hypothesis paragraph is retained as historical provenance.
