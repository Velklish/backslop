# BS-11 · Результат

**Закрыта 2026-09-05.** Выполнена.

`new` считает номер и sub-ID по объединению задач текущего дерева и `foreignTaskIds` (`lib/tasks.js`): файлы `<docs>/backlog/<статус>/` и каталоги `<docs>/archive/` других worktree по диску (`git worktree list --porcelain`, включая незакоммиченные) и деревья всех локальных веток (`git ls-tree -r --name-only <ветка> -- <docs>/backlog <docs>/archive`); пути — через realpath, проект в подкаталоге репозитория учитывается. Чужой номер, сдвинувший свой, печатается с источником: «worktree <путь> (<ветка>)» или «ветка <имя>». Без git — как раньше. `--from N` не понадобился: скан — три-четыре вызова git на команду. Проверено: `test/commands.test.mjs` — незакоммиченные задача и находка в чужом worktree сдвигают номер и sub-ID `new` на единицу с указанием worktree; после удаления worktree те же номера держит ветка `worker`; свободный номер идёт без сообщения; проект без git заводит первый номер. Мутационная проба: `foreignTaskIds`, возвращающий пусто, красит тест. Живой прогон в репозитории инструмента: 15 чужих номеров из основного worktree (`main`) и ветки задачи.
