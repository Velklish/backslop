# BS-33.1 · Результат

**Закрыта 2026-09-09.** Выполнена, с расхождением с постановкой: карточка просила тест-охрану на `--relative`, а замер показал, что флаг не покрывает merge-коммит — combined diff (`--cc`) печатает путь от toplevel git. Замер: репозиторий с проектом в `sub/`, ветка, merge `--no-ff --no-commit` с добавленным `sub/docs/m.md`; `git -C sub log --format=%x01%s --name-only --relative --cc -- docs` печатает `sub/docs/m.md` для merge-коммита и `docs/b.md`, `docs/c.md` для обычных. Флаг снят: префикс подкаталога срезает сама команда по `git rev-parse --show-prefix` (`gitOrFail`), а `-c core.quotePath=false` держит не-ASCII имена как есть — иначе путь печатался закавыченным и префикс не срезался. Проверка карточки «красный без `--relative`» заменена эквивалентной: «красный без среза префикса».

**Проверки.** Тест `archive --range: проект в подкаталоге репозитория — пути от корня проекта, и у merge-коммита тоже` (`test/commands.test.mjs`): проект в `sub/`, ветка, merge с правкой при слиянии, кириллическое имя, карточка трекера и файл вне проекта внутри диапазона — `deepEqual` на точный состав. Мутационные пробы после коммита (`node --test --test-name-pattern`): снять срез префикса — 1 из 1 красный; снять `-c core.quotePath=false` — 1 из 1 красный; снять `--cc` — 2 из 2 красных (этот тест и merge-тест BS-33.2).
