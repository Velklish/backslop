# BS-57.1 · Результат

**Закрыта 2026-09-22.** Выполнена. Класс закрыт одним местом на все поля, которые подставляются в managed-блок, а не отдельной копией проверок для `cli`: `validateBlockValue(value, field, lang)` применяет три запрета — перевод строки, обратная кавычка, метки `backslop:start` и `backslop:end` — к `docs`, `cli` и `probe`; `validateProbe` переведена на неё же. `prefix` в список не вошёл сознательно: `PREFIX_RE` не пропускает ни одного из этих символов, вызов был бы недостижимым кодом, и вместо него стоит тест, который краснеет при ослаблении регулярки.

**Находка по ходу, в области задачи, починена сразу.** Первый `init` строит конфиг сам и `loadConfig` не зовёт — поэтому `init --cli '… <!-- backslop:end -->'` на пустом проекте писал битый блок **с первого запуска**, а повторный `init` такой проект уже не чинил: он читает конфиг и отказывает. Проверка значения перенесена до `saveConfig`, с тестом. Изолированное ревью нашло, что то же самое открыто у `docs` из `--dir`, — закрыто тем же ходом, тест вырос до трёх случаев.

**Проверки.** `node bin/backslop.js gates --require-clean --json` на `8b11791` — exit 0, «гейтов 2, зелёных 2»; `lint` код 0, `npm test` код 0, tests 294 / pass 294 / fail 0. Против базы `1330e9e` (281 вердикт) снятых имён ноль. Мутационная проба: снят запрет меток в `lib/config.js` — `npm test` код 1, покраснели три теста (`config: probe`, `config: docs и cli`, `init --cli`); позже проба пересnята на `lib/config.js:127` и `lib/init.js:78` — код 1, 293/291/0, покраснели оба ожидавшихся.

**ADR не заводился, и это решение.** [ADR-021](../../adr/adr-021-probe-command-field.md) уже принял эти три запрета для значения, уезжающего в блок; здесь то же решение распространено на поля того же класса — новый контракт не появился, появились новые отказы по старому.

**Доки тем же ходом.** `docs/reference/01-layout.md` — класс полей назван явно, вместе с причиной отсутствия `prefix`; `README.ru.md` — раздел про `probe` получил тот же класс; `CHANGELOG.md` — запись со ссылкой на ADR-021.
