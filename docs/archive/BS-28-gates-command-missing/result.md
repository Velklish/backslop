# BS-28 · Результат

**Закрыта 2026-09-06.** Слита в [BS-14](../../backlog/queue/BS-14-gates-runner-missing.md). Обе записи предлагают одно — команду-раннер `backslop gates`, читающую поле `gates` из `backslop.json` и прогоняющую его команды тем же `exec()`-паттерном, что уже применяет `upgrade`. BS-14 описывает её полнее (`--keep-going`, `--json`, `--require-clean`, снимок дерева), поэтому принимающая — она.
