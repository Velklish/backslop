**Закрыта 2026-09-09.** Выполнена. Гейт 9 `lintClosedParent` (`lib/lint.js`, отдельная функция): находка `N.k` в `triage/`, чья задача `N` уже в архиве, — ошибка lint; находка в `queue/`, `active/` или `deferred/` при закрытом родителе не считается — она разобрана (так держится зелёным сам backslop: BS-2.1 в deferred при закрытой BS-2). `archive N [--range <база>..HEAD]` печатает файлы документации, тронутые ходом задачи, из двух выборок — коммиты диапазона и коммиты с номером задачи в заголовке; выборка по заголовку идёт всегда, флаг её расширяет.
