# BS-10 · Результат

**Закрыта 2026-09-05.** Выполнена.

`mv N queue --top | --after M` на задаче из `queue/` не переезжает, а меняет «Порядок»: место считается `placeInQueue` по очереди без самой задачи, соседи перенумеровываются шагом 10, когда целого места нет; без флага положения — отказ «уже в queue/; место — --top или --after M», `--after` на саму себя — отказ. `lint` (гейт 4) краснеет на двух файлах очереди с одним «Порядком» и называет первый файл. Проверено: `test/commands.test.mjs` — `--top` на задаче из очереди ставит 10 без переноса файла, тесная очередь перенумеровывается в 10/20/30/40, отказы без флага и на себя; `test/lint.test.mjs` — проба «два файла очереди с одним порядком». Мутационные пробы: отключение проверки дублей красит пробу lint, отключение перестановки — оба теста mv.
