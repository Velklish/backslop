# BS-17.1 · Результат

**Закрыта 2026-09-09.** Выполнена в части «проверяемый раннер»; часть «без зависимости от Keychain» закрыта предположением, не замером. Acceptance-тест `packed tarball installs locally…` в `test/release.test.mjs` получил раннер `describeRun`/`runOk`, различающий четыре исхода запуска: команда не запустилась (код ошибки, например ENOENT), снята сигналом, вернула ненулевой код (код и stderr), успех; пять ассертов `assert.equal(x.status, 0, x.stderr)` заменены на него, и отказ называет команду и причину вместо `null !== 0`. npm изолирован: свой HOME, `npm_config_globalconfig`, `userconfig` и `cache` внутри каталога проверки, унаследованные `npm_config_*` выброшены (под `npm test` их 12, включая `globalconfig=/opt/homebrew/etc/npmrc`), install идёт `--offline` на холодном кэше; инвариант «у пакета нет `dependencies`», на котором держится `--offline`, закреплён ассертом. Новый тест раннера проверяет исходы без npm и сети; на Windows он пропускается, и заголовок файла называет, что файл на Windows не рассчитан (шимы с shebang, `npm` без shell). Посылка карточки о падении с `SecItemCopyMatching failed -50` в сессии Claude Code не воспроизводится — она относится к песочнице Codex. Контр-замер worker'а: прежний тест с подставленным `.npmrc` (`registry=https://registry.invalid/`, битый токен) на HEAD `9d5360c` проходил 8 из 8, потому что у пакета нет `dependencies` и `npm install <tarball>` реестр не трогает; значит, если в песочнице падал сам `npm pack`, изоляция конфигурации отказ не снимет. Что правка даёт наверняка: отказ назовёт причину (`npm pack: снят сигналом SIGKILL` или `запуск не состоялся — <код>`). Проверить может только прогон в песочнице Codex.
