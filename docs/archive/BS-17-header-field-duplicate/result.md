# BS-17 · Результат

**Закрыта 2026-09-07.** Выполнена. Чтение и запись поля шапки сведены к одному правилу — первое вхождение среди RU/EN-алиасов по порядку строк файла: `readFields` больше не отдаёт последнее вхождение, `getField` идёт по строкам, а не по порядку алиасов. `setField` переписывает первое вхождение и удаляет остальные (сплайс в обратном порядке индексов, чтобы они не съезжали), `removeField` удаляет все. Дубль поэтому схлопывается первой же командой, и `mv N queue --top` больше не рапортует успех, ничего не переставив.
