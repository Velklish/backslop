# BS-58 · Результат

**Закрыта 2026-09-16.** Выполнена. Шаг 4 managed-блока `AGENTS.md` больше не требует мутационную пробу, не называя команды: команду объявляет новое поле `probe` в `backslop.json`, а текст предложения живёт отдельным шаблоном `templates/agents-probe.md` (английский близнец — `templates/en/agents-probe.md`) и подставляется в `{{probeRule}}` шага 4 только при объявленном поле. Поля нет — предложения про пробу в блоке нет вовсе, и `init` называет пропажу строкой вывода: правило, которое нечем исполнить, дороже отсутствия правила, но выкинуто оно должно быть вслух. Умолчания у поля нет — команда пробы у каждого репозитория своя. Форму значения проверяет `loadConfig` до записи блока тремя запретами, каждый закрывает свой класс целиком: перевод строки (вторая строка встаёт отдельным абзацем, и `N. …` в ней становится настоящим пунктом), обратная кавычка (шаблон ставит значение в код-спан, кавычка его закрывает) и собственные метки `backslop:start`/`backslop:end` (`upsertBlock` ищет границы по сырому тексту, метка обрывает блок, и следующий `init` дописывает хвост старого). `<` не запрещён намеренно: внутри код-спана он литерал, а запрет отверг бы законную команду с перенаправлением ввода. Смена контракта `backslop.json` записана в [ADR-021](../../adr/adr-021-probe-command-field.md).

**Сам backslop поля не объявляет** — своей команды пробы у репозитория нет, и это же делает self-host живой проверкой ветки «поля нет»: блок требования не несёт, а порядок пробы записан в `AGENTS.md` вне блока.

**Ревью нашло два класса обхода, и оба закрыты замером, а не рассуждением.** Раунд 1: значение с переводом строки давало `init` код 0 и второй пункт с номером 7 рядом с настоящим шагом 7, а значение с обратной кавычкой клало в блок сырой HTML. Раунд 2: довод «`<` не запрещён» был разобран по CommonMark и потому закрывал только то, что решает рендер, — границы managed-блока рендеру не подчиняются. Замерено: `"probe": "npm run probe <!-- backslop:end -->"` проходил без запрета, `AGENTS.md` рос на 897 байт с каждым `init` (2973 → 3870 → 4767), меток конца — четыре. Раунд 3: запрет был копией текста метки, не связанной с настоящими метками ничем, — теперь `BLOCK_MARKERS` одно написание на весь инструмент, а `BLOCK_START`, `BLOCK_END` и `BLOCK_MARKER_RE` собираются из него.

**Проверки.** Гейты на сведённом дереве приёмки: `node bin/backslop.js gates` — код 0, «гейтов 2, зелёных 2»; в составе `node bin/backslop.js lint` код 0 и `npm test` код 0, tests 266 / pass 266 / fail 0. Тот же счёт worker снял на своей голове `3108a861`. Мутационная проба после коммита: `{{probe}}` в шаблоне заменён литералом — красит «ru: шаг 4 называет команду пробы»; `const probeRule = cfg.probe` → `= true` — красит «ru: обязанности без инструмента в блоке нет»; `if (!cfg.probe)` → `if (false)` — красит «ru: init называет выпавшее требование, а не молчит»; переименование `BLOCK_MARKERS` — красит шесть проверок, включая «ru: второй init с probe не растит файл»; возврат `BLOCK_MARKER_RE` в литерал при переименованных метках — красит «запрет не узнаёт метку». Все мутации откачены, базовая точка каждой пробы — код 0.
