В принимающей задаче оставлены оба хода с границей между ними: примеры установки в README идут обобщённой формой (дрейфовать нечему), гейт сторожит те вхождения, где номер обязан быть настоящим. Наблюдение BS-41, которого не было в BS-29, — строка README не просто устарела, а неверно описывает поведение `init`: `defaultCli()` (`lib/config.js:20`) подставляет текущий `TOOL_VERSION`.
