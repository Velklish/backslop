# BS-63 · Результат

**Закрыта 2026-09-22.** Выполнена. `description` закавычен в самих шаблонах скиллов — они источник, и невалидным YAML был именно источник, — а `splitFrontmatter` научился снимать кавычки при чтении, иначе адаптер Cursor получил бы двойное экранирование: он кавычит значение сам через `JSON.stringify`. Правка охватила все четыре файла, которые падали по замеру (`backslop-task` и `backslop-batch` в обоих языковых слоях), плюс `seed` приведён к той же форме.

**Зачем это было дорого потребителю.** Файл скилла заявлен как markdown с YAML front matter, а значение содержало `: ` и плоским скаляром не разбиралось. Потребитель с проверкой front matter не мог обновлять пин без ручной правки после каждого `init`: закавыченные вручную файлы `upgrade` регенерировал без кавычек, и гейт краснел заново.

**Проба — своей проверкой, без зависимости.** YAML-парсер в набор не пришёл: зависимостей у пакета нет ни одной, и [ADR-003](../../adr/adr-003-node-stdlib-npx.md) их запрещает. Тест проверяет то самое правило YAML 1.2, о которое спотыкается разбор: плоский скаляр не содержит примет, а значение с приметой обязано быть закавычено и разбираться `JSON.parse`. Примет четыре, и набор шире первоначального: `': '`, `' #'`, хвостовое `':'` и индикатор первым символом — включая одинарную кавычку, потому что `'…'` легален в YAML и нелегален в JSON, и без неё правило имело бы дырку ровно в один символ.

Вторая проверка — на рендере `init --tools claude,cursor,codex`: значение в claude и codex закавычено и содержит `: `, а `JSON.parse` значения из `.mdc` равен `JSON.parse` значения из `SKILL.md`. Она и ловит двойное экранирование, которое прежняя проверка `description: ".+"` пропускала.

**Проверки.** `node bin/backslop.js gates --require-clean` на `967e5fa` — код 0, «гейтов 2, зелёных 2»; `lint` код 0, `npm test` код 0, tests 285 / pass 285 / fail 0. Против базы `1330e9e` (281) снятых имён ноль. Мутационные пробы: снято снятие кавычек в `lib/adapters.js` — код 1; сняты кавычки в шаблоне `backslop-task` — код 1, покраснели оба теста; **проба на новую примету** — у `backslop-seed` сняты кавычки и значение оканчивается на `:` — код 1: у него нет ни `': '`, ни `' #'`, то есть сработала ровно добавленная примета, а прежняя редакция прошла бы зелёной.

**Доки тем же ходом.** `docs/reference/01-layout.md`, `CHANGELOG.md`. Собственный гейт парности шаблонов (`frontmatterField`) остался построчным и к кавычкам слеп — это его задача, и переделывать его не требовалось.
