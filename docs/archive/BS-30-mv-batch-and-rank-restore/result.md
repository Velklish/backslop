# BS-30 · Результат

**Закрыта 2026-09-22.** Выполнена. Уход из `queue/` кладёт ранг в поле шапки «Прежний порядок» / «Previous order», `mv N queue --restore` ставит задачу обратно на него через `placeInQueue`: сохранённое число свободно — задача встаёт ровно на него, занято — перед тем, кто его занял, с перенумерацией шагом 10 на тесной очереди. Флаг берёт несколько номеров за вызов и обрабатывает пакет по убыванию сохранённых чисел, при равных — по убыванию номера; отказ читает числа всего пакета одним проходом до первого переноса и называет виновных поимённо. Возврат без флага сохранённое место отбрасывает и говорит об этом строкой на каждую задачу. Флаг возвращает место, а не гарантирует его. Раздел «Не входит» не нарушен: BS-26 выносила реализацию самого пакетного `mv`, а участие `--restore` в пакете — расширение области решением владельца, принятое по находке ревью.

**Проверки.** `node bin/backslop.js gates --require-clean` на `7770eb7` — код 0, «гейтов 2, зелёных 2», не запущено 0; `npm test` 324/324 при базе 314/314, снятых имён ноль, добавлено десять. Пять мутационных проб, все с кодом возврата 1 и нулевым остатком: чтение сохранённых чисел (`lib/mv.js:165`, шесть имён), направление обработки пакета (три), запись поля (два), нота об отброшенном месте (одно), арифметика места (`lib/tasks.js:482`, ожидалось одно, покраснело четыре — сеть шире ожидания). Изолированное ревью (claude-opus-5 xhigh, база `a52e383`): три круга, находок 4 → 2 → 1 → 0. Гейты на слитом дереве `main`: код 0, «гейтов 2, зелёных 2», `npm test` 346/346.

**Остаток назван, а не забыт.** Убывание снимает класс инверсий, а не все: перебор 300 000 конфигураций дал 81 971 инверсию при возрастании и 42 574 при убывании, минимальный контрпример — очередь 7 и 12, пакет 8, 10, 13, 13. Гарантии относительного порядка контракт не обещает ни в ADR, ни в справочнике, ни в CHANGELOG; остаток заведён карточкой [BS-30.1](../../backlog/queue/BS-30.1-restore-batch-order-not-guaranteed.md) в `triage/`.
