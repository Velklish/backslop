# BS-8 · today() берёт дату по UTC: поздним вечером «Взята» и «Закрыта» получают вчерашнее число

- **Область:** [02-cli](../../reference/02-cli.md)
- **Создана:** 2026-09-04
- **Зависимости:** нет
- **Взята:** 2026-09-05

## Контекст

Находка worker'а при переходе `ati-agents` на backslop (BL-541 там), 2026-09-05: `mv N active` в 01:xx по локальному времени (UTC+3) поставил «Взята: 2026-09-04» — `today()` в `lib/util.js` форматирует дату по UTC. Даты в трекере — календарные для того, кто работает; исправлено руками.

## Что сделать

- `today()` — локальная календарная дата (`getFullYear/getMonth/getDate`), не `toISOString().slice(0, 10)`.

## Не входит

- Часовой пояс в конфиге: дата — календарная для машины, на которой идёт работа.

## Проверки

- `test/commands.test.mjs`: `new` под `TZ=Etc/GMT-14` и `TZ=Etc/GMT+12` пишет разные «Создана» — эти пояса никогда не в одном календарном дне.
