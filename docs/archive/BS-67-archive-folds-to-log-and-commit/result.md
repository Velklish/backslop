# BS-67 · Результат

**Закрыта 2026-09-22.** Выполнена. `fold N` удаляет каталог `docs/archive/<id>-<slug>/`, дописывает строку в `docs/archive/LOG.md` и переводит входящие ссылки на её якорь; постановка и результат целиком уходят в заготовку сообщения коммита в stdout, отчёт — в stderr. `fold` без номера сворачивает накопленное, `--older-than` отбирает по дате закрытия, `--dry-run` ничего не пишет. `show N` печатает тело формой `git show <rev>:./<путь>` по путям из дерева ревизии. `archive N` не тронут: свёртка — отдельная команда, а не второй вызов той же. Причин пустой ревизии три, и ответ у них разный: без git и на незакоммиченном каталоге массовая свёртка отказывает до первой записи, потому что посмотреть в историю было нечем, а удаляет она только доказанное отсутствие тела. Тринадцатый гейт `lint` сторожит журнал; номера свёрнутых задач читаются из обоих источников, в том числе в чужих worktree и на локальных ветках.

**Свёртка накопленного.** 77 каталогов в 77 строк, 20 входящих ссылок в 14 файлах переписаны на якоря журнала, промахов 0; ещё 17 ссылок архив→архив ушли вместе с каталогами. Исходы: «выполнена» 67, «слита» 3, «отклонена» 1, тире 6. Все 154 тела достижимы по записанным ревизиям — проверено на приёмке командой `git cat-file -e <ревизия>:<путь>` по всем 77 строкам, промахов 0, с мутационной пробой на саму проверку: подстановка настоящего коммита, при котором тела ещё не было, красит её двумя промахами.

Мутационные пробы: `lib/log.js:20` (регистр якоря, пять имён объявлены до прогона и совпали), две на отказы пустой ревизии, одна на печать тела, две на ветку `--embed-missing`, одна на форму пути в проекте-подкаталоге. После разведения трёх причин она покрывает только каталог под `.gitignore` и переписанную историю.
