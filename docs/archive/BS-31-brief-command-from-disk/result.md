# BS-31 · Результат

**Закрыта 2026-09-09.** Выполнена. Команда `brief <N…> [--track "…"] [--neighbour "путь=track"] [--measurements]` (`lib/brief.js`, ADR-013) рендерит `templates/brief.md` (EN-близнец рядом, парность держится) и печатает бриф в stdout, ничего не отправляя. С диска берутся постановки задач — разделы «Что сделать» и «Не входит» через `scanTasks` и новые `SECTION_WORK`/`SECTION_OUT` с RU/EN-именами (EN-проект читает RU-карточку и наоборот), — а также `gates`, `prefix` и `cli` из `backslop.json`; `--measurements` вкладывает правило замера из `references/measurements.md` скилла batch. Решения оркестратора не выдумываются: без `--track` и `--neighbour` в брифе остаются заглушки TODO как сигнал «границы не решены». Отказы: номеров нет; задачи нет ни в статусах, ни в архиве — частичный бриф не печатается вовсе; архивная запись без `task.md` — отказ словами; `--neighbour` не в форме «путь=track». Транспорт worker'а бриф не называет — слот «Как поднять worker'а» остаётся в скилле оркестратора (ADR-003). Раздел «Бриф» скилла `backslop-batch` (RU/EN) заменён отсылкой к команде; правка BS-14 внутри прежнего перечня («критерий готовности» — итог `gates` числом) перенесена в `templates/brief.md`.
