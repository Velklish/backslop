# BS-13 · Результат

**Закрыта 2026-09-05.** Выполнена.

`parseCommandArgs` (`lib/util.js`) склеивает пару «строковый флаг, значение с ведущим дефисом» в `--флаг=значение` до `parseArgs`, если значение не совпадает с именем флага этой команды; совпадающее (`--title --queue`) остаётся отказом `parseArgs` с его же подсказкой `--title=-XYZ`. Справка RU и EN называет форму с «=». Проверено: `test/commands.test.mjs` — `new … --title "--strategy on spawn and review" --queue` и `--title "-x"` заводят задачи с этими заголовками, `adr … --title "--flag as a title"` — ADR; `--title --queue` — код 1 с подсказкой `--title=` и без файла; `--title=--queue` — задача с заголовком `--queue`; `help` содержит правило. Мутационная проба: отключение склейки красит тест.
