# BS-62 · archive N.k --into M: закрытие minor пачкой без своего result.md

- **Порядок:** 7
- **Область:** [02. CLI](../../reference/02-cli.md), [01. Раскладка](../../reference/01-layout.md), [03. Гейты lint](../../reference/03-lint.md)
- **Создана:** 2026-09-18
- **Зависимости:** [BS-61](../BS-61-minor-status/task.md)

## Контекст

[ADR-022](../../adr/adr-022-cost-decides-finding-fate.md): minor-находки чинятся пачкой — обычной карточкой M со списком номеров. Закрывать каждую запись обычным `archive N.k` значит писать `result.md` на каждую: десять приёмок на пачку из десяти. Пачка получает одну приёмку, а её записи уезжают в подкаталог архива пачки.

## Что сделать

- `archive N.k --into M`: файл из `minor/` переезжает в `docs/archive/<M-dir>/minor/<id>-<slug>.md` через `relocateTask` (ссылки обеих сторон переписаны), `result.md` не создаётся, список «доки тем же ходом» не считается. Вывод называет `result.md` пачки как место исхода.
- Отказы: задача не в `minor/` (подсказка про `archive N` с исходом «слита»); M не найдена; M сама лежит в `minor/`; M ещё не закрыта — каталог незакрытой пачки в архиве читался бы вторым файлом её номера, поэтому пачка закрывается первой; `--range` вместе с `--into`.
- `scanTasks` видит `archive/<dir>/minor/*.md` как закрытые записи, `foreignTaskIds` считает их номера: `lintMentions` не краснеет на упоминании закрытой minor, `new --parent` не выдаёт занятый `N.k`.
- `lint`, правило архива: в каталоге задачи допускается подкаталог `minor/` с файлами по шаблону имени; чужое имя внутри — ошибка.
- Справочник 01/02/03, `CHANGELOG.md`.

## Не входит

- Автоматическое заполнение `result.md` пачки: исход по записям пишет approver.
- Возврат записи из архива пачки обратно в `minor/`: руками, как любой возврат из архива.

## Проверки

- Перенос: файл на новом месте, входящая ссылка из другого дока переписана, `result.md` рядом не появился (тест в `test/commands.test.mjs`).
- Три отказа выходят кодом 1 с текстом причины (тест).
- `lint` зелёный после переноса; упоминание `N.k` в `docs/` зелёное; красная проба «чужой файл в `archive/<M>/minor/`» в `test/lint.test.mjs`.
- `node bin/backslop.js gates` зелёный, счёт тестов до и после назван в `result.md`.
