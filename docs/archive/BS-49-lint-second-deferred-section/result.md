# BS-49 · Результат

**Закрыта 2026-09-13.** Две половины: `mv N deferred` дописывал шаблонный раздел поверх уже заполненного, а `lint` не видел ни второго раздела, ни незаполненной заглушки нигде, кроме `result.md` архива. Теперь `mv` не дублирует готовый раздел, гейт заглушек распространён на весь `docs/backlog/**`, а повторный раздел «Отложено» краснит.

**Ключевая правка не та, что просила карточка, и нашлась она на мне.** Карточка требовала красный на заглушке в любом файле бэклога, и первая редакция сделала это поиском подстроки. Оркестратор поймал это на себе в тот же вечер: попытался написать в поле «Область» соседней карточки, что `lint` сторожит такие заглушки, и получил «поле не заполнено» **при полностью заполненном поле**. То есть карточку про наивную проверку нельзя было описать своими словами, пока проверка наивна. Отсюда предмет уточнился: нужен признак **незаполненного значения**, а не вхождение текста.

Ревью нашло обратную ошибку этой же правки: сведя проверку к форме целой физической строки, она перестала ловить то, что ловила прежняя — канонический `new --parent` печатал улику на одной строке с другим текстом, и карточка находки выходила зелёной с пустой уликой. Закрыто выносом слота на отдельную строку и разбором **значения поля**.

**Вторая находка ревью показала ту же болезнь в другом месте:** заголовок раздела внутри ограждённого блока кода считался настоящим, и карточка с примером в ограждении получала ложный дубль. Первая починка сделала fence-aware только счётчик, а `mv` продолжал брать сырое тело — состояния разошлись. Закрыто **единым** `sectionRanges`: границы ищутся один раз по очищенному тексту, тело режется по тем же индексам из исходных строк, и все четыре потребителя — `mv`, `lint`, `status`, `brief` — идут через него. Ревьюер подтвердил, что пятого отдельного поиска в `lib/` не осталось.

**Проверка.** Гейты на слитом дереве: `lint` код 0, `npm test` код 0 — 2 из 2. Мутационные пробы по каждой правке: возврат к поиску подстроки красит три теста, включая пробу на прозу; отключение разбора значения — пять падений; снятие `blankFences` — два. Все восстановлены.

**Документация в том же проходе.** `docs/reference/02-cli.md`, `docs/reference/03-lint.md`, `docs/backlog/README.md` и шаблоны на обоих языках, `README.md`, `README.ru.md`, `CHANGELOG.md`.

**Что осталось незакрытым.** Ничего по этой карточке.
