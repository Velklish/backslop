# BS-49 · `mv N deferred` дописывает шаблон «Отложено» поверх заполненного, а `lint` второй раздел и `[TODO]` в docs/backlog/** не видит

- **Порядок:** 60
- **Область:** `lib/lint.js` (гейт разделов и незаполненных заглушек), `lib/mv.js` (дописывание шаблона «Отложено»), `templates/` и `templates/en/` — шаблон отложенного раздела
- **Создана:** 2026-09-10, постановка из репозитория-потребителя (ati-agents, BL-514.4)
- **Зависимости:** нет

## Контекст

`mv N deferred` дописывает шаблонный раздел «Отложено» в конец файла и печатает «заполни раздел». Заполняющий пишет свой раздел там, где ему удобно, и шаблонный остаётся в дереве с двумя заглушками `[TODO]`. У потребителя это ловилось приёмкой дважды подряд (ati-agents `BL-552.3`, `BL-514.3`): в обоих файлах `grep -c '^## Отложено'` давал `2`, `grep -c '\[TODO'` давал `2`, а `lint` возвращал код 0 — он находит заполненный раздел и на второй не смотрит. Правило прозой («раздел один и последний, заполняй шаблон») у потребителя записано; гейта на это нет.

## Что сделать

- `lint`: красный на втором разделе «Отложено» в файле `deferred/` и на `[TODO` в любом файле `docs/backlog/**` (сегодня `[TODO]` ловится только в `result.md` архива).
- `mv N deferred`: не дописывать шаблон, если раздел «Отложено» в файле уже есть — печатать «раздел есть, проверь причину и условие возврата».

## Живой случай — 2026-09-13

Гейт «Область» ловит подстроку заглушки **где угодно в строке**, а не только на месте незаполненного поля. Замер: попытка написать в «Область» этой самой карточки слова о том, что `lint.js` сторожит такие заглушки, дала `lint` exit 1 с сообщением «„Область“ не заполнена» — при том что поле было заполнено полностью. То есть карточку про наивную проверку заглушек нельзя описать своими словами, пока проверка наивна.

Это уточняет предмет: расширяя гейт на весь `docs/backlog/**`, поиск подстроки брать нельзя — иначе каждая карточка, которая говорит о заглушках, станет красной. Нужен признак незаполненного поля (заглушка занимает значение целиком), а не вхождение текста.

## Не входит

- `[TODO]` в `result.md` — уже ловится.

## Проверки

- Фикстура: файл с заполненным разделом «Отложено» и дописанным шаблоном — `lint` красный; после снятия шаблона — зелёный. `mv N deferred` на файле с готовым разделом не меняет его.
