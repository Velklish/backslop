# BS-32 · Результат

**Закрыта 2026-09-09.** Выполнена. Команда `tracks [--json]` (`lib/tracks.js`, ADR-019) печатает по каждому чужому worktree и по каждой ветке с коммитами задач мимо `HEAD`: путь, ветку (или sha detached-worktree), влита ли в `HEAD` (`merge-base --is-ancestor`, для detached — по sha), коммиты `<prefix>-N` вне `HEAD` (`--grep` как предфильтр, решает заголовок из `%s`, как в `archive`), незакоммиченное в дереве worktree (`status --porcelain` внутри него; пустой список «незакоммиченного нет» и `null` «дерева нет» — разные значения). Влитость и неслитые коммиты печатаются порознь: после переписи истории любой факт поодиночке врёт. Критерий для ветки без worktree — коммиты задач мимо `HEAD`, а не «есть в истории» (иначе в перечень лезла любая ветка от `main`); worktree перечисляется всегда. Удаления нет и не будет — решение ADR-019; живые сессии команда не видит, это знание harness'а, названо в разделе «Конец захода» обоих скиллов. Посылка карточки «переиспользуя `foreignTaskIds`» мертва: разбор porcelain там вшит в цикл по каталогам статусов; шесть строк разбора повторены сознательно — находка BS-32.1 (в очереди).
