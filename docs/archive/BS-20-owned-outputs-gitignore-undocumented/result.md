# BS-20 · Результат

**Закрыта 2026-09-09.** Выполнена по механизму (а): `init` держит в `.gitignore` проекта блок между `# backslop:start` и `# backslop:end` (html-комментарий в синтаксисе `.gitignore` был бы шаблоном имени файла); строки — glob по корню выбранного harness (`.claude/skills/backslop-*` и т. п.) из реестра BS-42, состав скиллов перестал быть частью правила; `/CLAUDE.md` — только когда на диске лежит наш stub (`@AGENTS.md`), иначе блок спрятал бы от git пользовательский файл; блок заводится, когда есть что игнорировать или когда он уже был — self-host с `tools: []` печатает «`.gitignore`: не нужен», и обычный `init` не делает tracked tree грязным; `--tools none` вычищает состав, оставляя блок; чужие строки файла переживают смену набора. `upsertBlock` обобщён параметром маркеров с прежним умолчанием для `AGENTS.md`. Гейт `lint` по индексу git не заводится: втащил бы в `lint` зависимость от git и молчал бы там, где его нет. Собственный `.gitignore` репозитория приведён к той же glob-форме, `.claude/worktrees/` вынесен отдельно. Решение — ADR-012 с тремя осями (форма строк, маркеры, `/CLAUDE.md`). Цена, названная в ADR: первый `init` после обновления допишет блок в конец `.gitignore` потребителя; уже закоммиченные owned outputs правкой не чинятся; три разошедшихся `.gitignore` потребителей сами не сойдутся — блок дописывается рядом, прежние рукописные строки снимает человек.
