# BS-42 · Результат

**Закрыта 2026-09-09.** Выполнена. Состав adapters сведён к одному источнику — `lib/adapters-registry.js`: таблица `ADAPTERS` (`{ id, root }`), из неё `TOOLS`, `ADAPTER_ROOTS`, `adapterRootRel(id)`, рядом `CANONICAL_SKILL`; модуль ничего не импортирует. Из него выведены `TOOLS` в `config.js` (реэкспорт), `adapterRoots` и ключи `counts` в `adapters.js`, `ownedAdapterFiles`, `LEGACY_ADAPTER_RELS`, `isAdapterRel`, `cursorRel` в `adapter-ownership.js`; ветвление `renderAdapters` по трём adapter'ам заменено общим `adapterRel` с одним особым случаем Cursor. Признак «репозиторий инструмента» для гейта парности — тождество каталога `templates` проекта с `TEMPLATES_DIR` запущенного CLI через `realpathSync` обеих сторон (`sameDir`, с try/catch на несуществующий путь): переименование canonical-скилла гейт не выключает, пропавший слой `templates/en/` даёт честную ошибку, чужой проект со своим `templates/skills/` гейт не красит. Первая редакция признака «оба слоя на месте» была забракована ревью — она выключала гейт при удалении `templates/en/` молча, ровно тем способом, который задача закрывала. Гейт 11 (релиз, BS-29) переведён на тот же признак: файл-маркер там наследовал ту же дыру. Цена признака названа в 03-lint: тождество держится, пока `lint` запущен той же копией инструмента, что лежит рядом с `templates/`; прогон `npx github:…#vX lint` в самом репозитории выключит гейт — штатные гейты зовут `node bin/backslop.js`. `.gitignore` остаётся явным списком (синтаксис git состав из кода не берёт), но в той же glob-форме, что генерирует `init` после BS-20.
