# BS-4 · Команда upgrade и пин версии в backslop.json

- **Область:** [reference/02](../../reference/02-cli.md)
- **Создана:** 2026-09-03
- **Зависимости:** нет; BS-2 меняет только форму пина
- **Взята:** 2026-09-03

## Контекст

`npx github:Velklish/backslop` без тега — HEAD ветки `main`: npm 11 при каждом запуске делает `git ls-remote` и переклонирует пакет, когда SHA изменился (улика: `libnpmexec/lib/index.js`, функция `missingFromTree` — для git-спеки сравнивается `node.package.resolved` с `manifest._resolved`). Каждый проект получает последнюю версию без своего ведома: правка шаблонов меняет поведение всех проектов сразу, а без сети команда не работает даже при попадании в кэш.

Пина версии в проекте нет — `init` пишет `cli` без тега. Штампа версии в `backslop.json` нет, миграции формата нет: смена шапки задачи или каталогов статусов покрасит `lint` у старых файлов без подсказки, что делать.

## Что сделать

1. `init` пишет `cli` с тегом своей версии — `npx github:Velklish/backslop#v<версия>` — и поле `version` в `backslop.json`; `gates` получает тот же пин.
2. Команда `upgrade`: последняя версия по `git ls-remote --tags`; замена пина в `cli` и `gates`; повторный `init` новой версией (`npx <новый пин> init`); при отставании штампа — `migrate` формата, в этой версии — заглушка с ответом «мигрировать нечего»; выжимка секций CHANGELOG между версиями в вывод.
3. `lint`: предупреждение, а не ошибка, когда `version` в конфиге старее версии инструмента — «скелет старее инструмента, запусти upgrade».
4. Доки тем же ходом: справочник 01 и 02, README (раздел «Обновление»), CHANGELOG; в `agents-section.md` — упоминание `upgrade`.

## Не входит

- Публикация в npm (BS-2): меняет только форму пина на `npx backslop@<версия>`.
- Обновление по расписанию и уведомления о новых версиях.
- Доставка скиллов плагином Claude Code: вторая половина поставки против «одной версии по построению».

## Проверки

- e2e: `init` пишет пин с тегом текущей версии; `upgrade` во временном проекте с подставным git-репозиторием на два тега переставляет пин, переписывает скиллы и печатает выжимку CHANGELOG; конфиг без `version` читается как старый и получает штамп.
- `lint` на проекте со старым штампом — предупреждение, код возврата 0.
- Мутационная проба: снять сравнение пина в `upgrade` — тест на замену пина краснеет.
