# 03. Гейты lint

`lint` ([lib/lint.js](../../lib/lint.js)) перечисляет всё найденное и выходит кодом 1 при ошибках. Каждый гейт ловит то, что руками разъезжается молча; у каждого в [test/lint.test.mjs](../../test/lint.test.mjs) есть красная проба — мутация зелёного проекта, без которой гейт нечем отличить от холостого.

| № | Гейт | Что ловит | Чем чинится |
|---|---|---|---|
| 1 | Ссылки | битая относительная ссылка в `docs/**`, корневых `*.md` и `.claude/skills/backslop-*`; формы — голая, с заголовком, в угловых скобках, reference-style; код не считается | поправить путь; переезд задачи делать через `archive`, он переписывает ссылки сам |
| 2 | Номера | номер занят дважды; заголовок первой строки называет другой номер; находка `N.k` без задачи `N`; в каталоге статуса файл не по шаблону имени или подкаталог | перезавести файл с новым номером (`new`), поправить заголовок |
| 3 | Раскладка бэклога | markdown прямо в `docs/backlog/` кроме README; каталог, не являющийся статусом; отсутствующий каталог статуса | перенести файл в каталог статуса; создать каталог с `.gitkeep` |
| 4 | Поля статусов | в `queue/` нет целого «Порядка»; в `active/` нет даты «Взята»; в `deferred/` нет раздела «Отложено» или в нём остался `[TODO]` | `mv` ставит поля сам; заполнить причину и условие возврата |
| 5 | Архив | каталог не по шаблону имени; нет `task.md` или `result.md`; в `result.md` остался `[TODO]` | дописать результат — это и есть напоминание approver'у |
| 6 | Упоминания | `<prefix>-N` или `N.k` в `docs/**` и `CHANGELOG.md`, за которым нет файла ни в статусах, ни в архиве; блоки кода — примеры и не считаются | поправить номер или завести задачу |
| 7 | CHANGELOG | заголовок записи `- **…**` повторяется внутри одной секции | совпавший заголовок — правка одной записи: оставить одну редакцию |
| 8 | ADR | ADR без строки в таблице `docs/README.md`; два файла с одним номером; файл в `adr/` не по шаблону имени | добавить строку; перенумеровать |

Обходчик markdown у гейтов и у `archive` один — [lib/mdwalk.js](../../lib/mdwalk.js): пропускаются `.git`, `node_modules` и `.claude/worktrees` (рабочие копии субагентов). Множества разные по замыслу: гейт ссылок смотрит `docs/**`, корневые `*.md` и скиллы backslop, а `archive` переписывает входящие ссылки по всему репозиторию — чужой каталог с markdown может ссылаться на задачу, и после переезда ссылка должна остаться живой. Корневые пути `/docs/…` гейт резолвит от корня проекта, `archive` их не трогает; сноски `[^1]:` объявлением ссылки не считаются; блок кода закрывается только фенсом того же знака не короче открывающего, незакрытый идёт до конца файла.
