# BS-192.27 · 03 Lint gates: link text is a page number

- **Scope:** [03. Lint gates](../../reference/03-lint.md)

- **Dependencies:** none

## Context

Finding discovered while working on BS-192.
Evidence: docs/reference/03-lint.md, 4 links on 4 lines, listed by line and the text before the link: 13 `[01]` after “…no word of the outcome table ([01] → 01-layout.md#archive”; 13 `[02]` after “…sal carries the same message ([02] → 02-cli.md”; 21 `[01]` after “…e journal line to the form of [01] → 01-layout.md#archive”; 62 `[01]` after “…ed `SOURCE.md` beside it, see [01] → 01-layout.md#adapter-ownership” — S9 (High): link text `[01]` and `[02]` names a page by its number. Quick Diagnostic row 8 fails.
Quote a file inside a “<!-- quote:path --> … <!-- /quote -->” block rather than by line number: numbers drift silently, the block is guarded by lint. If unverified, state it as an assumption.
