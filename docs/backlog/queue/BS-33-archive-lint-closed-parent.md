# BS-33 · `archive N` не подставляет в `result.md` механические строки, а `lint` не ловит закрытую задачу с неразобранным `triage/`: находка проходит проверку и с архивным родителем

- **Порядок:** 60
- **Область:** [reference/01](../../reference/01-layout.md), [reference/03](../../reference/03-lint.md), `lib/lint.js`, `lib/archive.js`, `lib/tasks.js`, `templates/result.md`
- **Создана:** 2026-09-06
- **Зависимости:** нет

## Контекст

Проверено на текущем HEAD.

Гейт «родитель находки» — `lib/lint.js:109-113`: `for (const t of tasks) { if (t.sub !== null && !tasks.some((p) => p.num === t.num && p.sub === null)) err(...) }`. Массив `tasks` строит `scanTasks` (`lib/tasks.js:92-118`), и он включает архивные записи наравне с активными: цикл по `STATUSES` (строки 95-103) даёт задачи из `triage/queue/active/deferred`, отдельный проход по `dirs.archive` (строки 105-116) добавляет туда же записи со `status: 'archive'` — без различения статуса при проверке `p.sub === null`. Поэтому находка `N.k`, чей родитель `N` уже закрыт и лежит в `archive/`, проходит проверку «есть родитель» так же, как если бы `N` была активна — сигнала «задача закрыта, а находка по ней не разобрана» этот гейт не даёт. Сам проект уже фиксирует этот промах как повторяющийся: `templates/skills/backslop-task/SKILL.md:68` — «Задача закрыта, а triage не разобран» — в разделе «Живые промахи».

Второй компонент — `lib/archive.js:59-61`: `result.md` кладётся строго шаблоном `renderProjectTemplate(cfg, 'result.md', { id, date, prefix })` с тремя `[TODO]` (`templates/result.md`: исход, чем проверено, какие доки поправлены). Ни `--gates`, ни `--range`, ни список изменённых файлов документации команда не подставляет — все три пишет approver по памяти. Задачи про это нет ни в одном каталоге бэклога backslop и не в архиве.

## Что сделать

- Новый гейт в `lib/lint.js` (или предупреждение в `lib/lint.js`, `note`, по образцу `lintVersion`): для каждой находки `N.k` в `triage/`, если родительская задача `N` находится в `archive/` (а не в `triage/queue/active/deferred`), — ошибка «находка {{id}} лежит в triage/, а задача {{prefix}}-N закрыта».
- `backslop archive N [--range <база>..HEAD]`: печатает (не решает) список файлов под `docs/` и `CHANGELOG.md`, изменённых коммитами диапазона или коммитами с префиксом `{{prefix}}-N:` — approver копирует нужное в раздел «Доки тем же ходом» `result.md` вручную; строки «Исход» и «Проверки» approver пишет сам, автоматической подстановкой не заменяются.
- Обновить `docs/reference/01-layout.md` (раздел «Архив») и `docs/reference/03-lint.md` (таблица гейтов, число гейтов) тем же ходом.
- Обновить `docs/reference/02-cli.md`: флаг `--range` у команды `archive`.
- Запись в `CHANGELOG.md`.

## Не входит

- Автоматическая подстановка «Исход» и «Проверки» в `result.md` — это решение approver'а по существу задачи, не механическая строка; `--range` только печатает список файлов, ничего не вписывает в `result.md` сам.
- Общий раннер гейтов из `backslop.json` — здесь только конкретный гейт про закрытого родителя, без новой инфраструктуры запуска гейтов.
