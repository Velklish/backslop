# BS-197.1 · Without a declared probe, backslop-task leads to no mutation check at all

- **Order:** 1077
- **Scope:** [01. Layout](../../reference/01-layout.md) § Templates
- **Created:** 2026-10-01
- **Dependencies:** none
- **Cost:** major

## Context

Finding discovered while working on BS-197.
Evidence: the BS-197 skill-creator runs (throwaway project `textkit`, `init --lang en --tools claude`, no `probe` field in `backslop.json`; executors are sonnet subagents). Prompt of eval `task-take-first`: "hey, can you grab whatever's at the top of the backlog queue and get it done? I'll review the diff myself before anything gets closed out, so take it as far as it can go before that." With v0.12.0 (`806779d`) the agent broke the fix after committing and showed `npm test` red, then restored it, in 3 of 3 runs; with `main` at `cb3bb26` it ran no mutation check in 0 of 3 runs (grep for "mutation|probe" in the three new transcripts: 0 matches). Eval `task-worker-finding-boundary` (worker implements APP-1 under an orchestrator): old ran the check, new did not (1 run each). During batch integration old ran one in 2 of 4 runs, prompted by its `result.md` stub, new in 0 of 4. All assertions pass for both versions, so the benchmark score does not show it.

The fixture, to rerun without the BS-197 scratch: a git project `textkit` with `src/text.js` (`slugify`, `truncate`, `words`), three `node:test` tests and `"test": "node --test"` in `package.json`, set up by `init --lang en --tools claude --prefix APP`. Its `gates` in `backslop.json` are `lint` and `{"command": "npm test", "when": ["src/**", "test/**", "package.json"]}`, and `docs/reference/01-text.md` describes the three helpers. The queue holds APP-1 "Slugs are lowercase" (Order 10: `slugify` returns lowercase output, a test with capital letters, reference and CHANGELOG updated) and APP-2 "Truncate fits the ellipsis into n" (Order 20), committed on `main`.

This follows the rule of [ADR-041](../../adr/adr-041-probe-command.md): without `probe`, the block, the skill, the brief and the result stub carry no probe sentence. The v0.12.0 text also asked for a hand-made check ("break the code and make sure the test fails", "the commit comes first"), which needs no declared command; that request went away with the probe command.

## Owner decision

Owner decision (2026-10-02): in a project without `probe`, the `backslop-task` skill again tells the agent to commit, break the code by hand and confirm that a test fails, in both languages. [ADR-041](../../adr/adr-041-probe-command.md) is rewritten in place. It goes before the release v0.14.0, so that the release does not remove the sentence and the next version bring it back.
