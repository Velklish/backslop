# BS-1 · Английский слой: шаблоны, скиллы и README

- **Порядок:** 10
- **Область:** [reference/01](../../reference/01-layout.md)
- **Создана:** 2026-09-03
- **Зависимости:** стабилизация русских текстов скиллов после первого живого прогона на чужом проекте

## Контекст

Все шаблоны docs, скиллы и README — на русском: процесс отлажен на русскоязычных заходах, и переводить его до первого чужого прогона было бы двойной работой. Для проектов с англоязычной командой инструмент сейчас не годится: блок в `AGENTS.md` и скиллы агент прочитает, но человек в команде — нет.

## Что сделать

- Второй комплект шаблонов `templates/en/` (docs, skills, agents-section, task, result, adr) с тем же составом и подстановками.
- Флаг `init --lang en`, поле `lang` в `backslop.json`; команды `new`, `adr`, `archive` берут шаблон по языку конфига.
- README на английском рядом с русским или общий с переключением.
- Гейт равенства состава: набор файлов и подстановок в `templates/en/` совпадает с русским, иначе `lint` репозитория инструмента красный.

## Не входит

- Перевод содержимого docs в чужих проектах: посев `backslop-seed` идёт на языке проекта.

## Проверки

- `init --lang en` во временном проекте не оставляет кириллицы в `docs/**`, `.claude/skills/backslop-*` и блоке `AGENTS.md`.
- `npm test` зелёный; e2e init проходит на обоих языках.
