# BS-79 · Пачка minor: команды CLI — mv, init, fold, merge-changelog и гейты lint на них

- **Порядок:** 210
- **Область:** [02. CLI](../../reference/02-cli.md)
- **Создана:** 2026-09-24
- **Зависимости:** нет

## Контекст

Пачка minor-записей области 02 по правилу [docs/backlog/README.md](../README.md): в `minor/` накопилось десять записей, и заход 2026-09-24 трогает `mv`, `init`, `fold`, `merge-changelog` и гейты `lint`. Развилки, которые записи оставляли владельцу, решены им 2026-09-24 — решение стоит у каждой записи ниже и продублировано в её файле.

## Что сделать

По одной строке на запись; исход каждой — строкой в `result.md` пачки, закрытие — `node bin/backslop.js archive N.k --into 79` после `archive 79` и до `fold 79`.

- [BS-64.2](../minor/BS-64.2-mv-into-minor-carries-task-form.md) и [BS-64.3](../minor/BS-64.3-mv-minor-adds-no-evidence-and-lint-does-not-require-it.md) — решение владельца: вариант Б+. `mv N[.k] minor` требует улику: непустой раздел «Улика» без заглушки либо флаг `--evidence "…"`, который пишет раздел так же, как `new --minor`; без улики — отказ до переноса. При переезде файла формы `task.md` заглушки постановки («Что сделать», «Не входит», «Проверки», целиком состоящие из `[TODO…]`) снимаются, написанный текст сохраняется; «Контекст» с текстом становится «Уликой», когда раздела «Улика» нет. Гейт `lint` в `minor/` требует раздел «Улика» без заглушки — вторая дверь закрывается с той же стороны, что и `new --minor` ([ADR-029](../../adr/adr-029-minor-finding-requires-evidence.md)).
- [BS-65.1](../minor/BS-65.1-no-gate-catches-nonprintable-bytes-in-source.md) — решение владельца: гейт `lint` на непечатаемый байт (код ниже 0x09, кроме табуляции; NUL и SOH — живой случай) в отслеживаемых текстовых файлах `lib/**`, `bin/**`, `test/**`, `templates/**`, `scripts/**` и `docs/**`; списка исключений нет до первого законного случая; красная проба в `test/lint.test.mjs`.
- [BS-58.2](../minor/BS-58.2-init-has-no-root-flag.md) — решение владельца: `init --tools <не none>` отказывает, когда cwd — корень самого backslop (признак self-host — тождество `templates` с каталогом инструмента, как у гейта равенства шаблонов); сквозной `--root` не заводится.
- [BS-70.1](../minor/BS-70.1-merge-changelog-base-drop-eats-blank-line.md) — `merge-changelog --base`, снимая последний блок theirs, оставляет пустую строку перед следующей секцией `## `.
- [BS-76.1](../minor/BS-76.1-fold-date-falls-back-to-fold-day.md) — дата закрытия записи без даты в `result.md` — дата коммита ревизии тела (`git log -1 --format=%cs <rev>`); день свёртки остаётся только для строки без ревизии; сказать в справочнике 01 § «Архив».
- [BS-76.4](../minor/BS-76.4-fold-orders-journal-by-number-but-header-promises-closing-order.md) — массовая свёртка пишет строки журнала в порядке дат закрытия (тех же, что стоят в строках), равные даты — по номеру; шапка журнала и справочник 01 говорят то же.
- [BS-76.2](../minor/BS-76.2-result-outcome-word-not-enforced.md) — решение владельца: гейт `lint` — первый абзац `result.md` каждого несвёрнутого каталога `archive/*/` несёт слово исхода из словаря (выполнена, отклонена, слита в `<prefix>-N`, снята с плана и английские пары); голое «закрыта» / «closed» / «done» без слова исхода — ошибка с именем файла; фолбэк в `lib/log.js` остаётся для старых записей при свёртке. Красная проба в `test/lint.test.mjs`; шаблон `templates/result.md` обоих языков и справочник 01 называют требование.
- [BS-67.1](../minor/BS-67.1-result-outcome-not-a-field.md) — решение владельца: отклонена. Поле «Исход» в `result.md` не заводится: слово исхода в первом абзаце становится контрактом через гейт BS-76.2, миграции у потребителей нет. Исход записи в `result.md` пачки — «отклонена».
- [BS-73.1](../minor/BS-73.1-archive-skips-rooted-incoming-link.md) — `archive N` переписывает и корневую входящую ссылку на переехавший файл: `rewriteIncomingLinks` через `mapLinks` пропускает корневые пути, верно только для ссылок самого переехавшего файла; та же форма, что BS-73 закрыла для `fold`.
- [BS-74.1](../minor/BS-74.1-fold-draft-intro-claims-only-storage.md) — вступление заготовки `fold N` (`draftOne`) различает строку с ревизией (заготовка — копия, тело достаёт `show N`) и строку с «—» (единственное хранилище), как это уже делает stderr после BS-74.
- [BS-74.2](../minor/BS-74.2-bulk-fold-demands-draft-without-bodies.md) — последняя строка stderr массовой свёртки: без `--embed-missing` тел в заготовке нет, и строка называет, что тела лежат в истории по ревизиям строк; требование «иначе тело потеряется» остаётся только для заготовки с телами (`--embed-missing`).
- [BS-78.1](../minor/BS-78.1-show-spawn-failure-says-code-null.md) — отказ git у `show`, `fold` и прочих команд при `status null` (git не запустился, ENOBUFS, timeout) называет причину из `error`/`stderr`, а не «код null».

- Парсер исхода и ревизия свёртки — [BS-76.3](../../archive/LOG.md#bs-76.3), [BS-76.5](../../archive/LOG.md#bs-76.5).
