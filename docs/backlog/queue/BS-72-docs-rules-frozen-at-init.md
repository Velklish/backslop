# BS-72 · Правила ведения у потребителя замерзают на init: upgrade их не перерисовывает

- **Порядок:** 120
- **Область:** [init и upgrade](../../reference/02-cli.md)
- **Создана:** 2026-09-22
- **Зависимости:** нет

## Контекст

Находка ревью BS-30 (reviewer, 2026-09-22), проверена по коду оркестратором. Цена — major.

Блок `AGENTS.md` у потребителя говорит агенту: «Правила ведения — `docs/backlog/README.md`». Сам блок — adapter output, и `upgrade` его перерисовывает. Файл, на который блок показывает, не перерисовывается никогда: `init` пропускает существующее (`lib/init.js:131`, комментарий «Скелет docs: каждый файл шаблона — один раз; существующий не трогается»), а `upgrade` доводит обновление именно вызовом `init` (`lib/upgrade.js:171`).

Итог: после любого обновления свежий блок показывает на замороженный на `init` текст правил. Расходятся не оформление, а предписания — агент в проекте потребителя исполняет правила той версии, на которой проект когда-то завели.

Пара «шаблон ↔ `docs/`» объявлена в `AGENTS.md` этого репозитория рендером 1:1 — то есть `docs/backlog/README.md` носит процессный текст инструмента, а не проектное содержание. В этом он отличается от соседей по каталогу (`GLOSSARY.md`, `README.md`, `ROADMAP.md`, `reference/README.md`), которые наполняются проектом осознанно.

Живой пример из захода 2026-09-22: BS-30 переписала правило места в очереди в трёх файлах — `templates/docs/backlog/README.md`, его en-близнеце и рендере `docs/backlog/README.md`. К потребителю, обновившемуся с 0.9.x, доедут скиллы с новым правилом и не доедет сам текст правил. То же касается всех текстовых правок этого релиза.

## Что сделать

- **Решение владельца 2026-09-24:** `docs/backlog/README.md` у потребителя принадлежит инструменту — `upgrade` перерисовывает процессные файлы `docs/` из шаблона своей версии. Не выбраны: оставлять файл и сторожить расхождение `lint`'ом; переносить правила в adapter output — блок `AGENTS.md` грузится в каждую сессию агента.
- Исполнить, описать в справочнике и закрыть ADR: у файла появляется владелец, это контракт раскладки.

## Не входит

- Перерисовка проектных файлов `docs/` (`GLOSSARY.md`, `README.md`, `ROADMAP.md`, `reference/README.md`) — они наполняются проектом осознанно.
- Судьба уже разошедшихся у потребителей копий: миграция чужих текстов в область этой задачи не входит.

## Проверки

- Проект на предыдущей версии, в шаблоне правил изменена строка: после `upgrade` состояние файла правил соответствует выбранному решению, и это видно тестом.
- Красная проба на выбранный сторож: вернуть прежнее поведение — проверка краснеет.
- `node bin/backslop.js gates` зелёный.
