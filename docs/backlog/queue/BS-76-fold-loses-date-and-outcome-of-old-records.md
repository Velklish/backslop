# BS-76 · Свёртка теряет дату и исход старых записей: дата читается только из первого абзаца, исход — только в трёх словесных формах

- **Порядок:** 40
- **Область:** [02-cli](../../reference/02-cli.md), `lib/log.js`, `lib/fold.js`
- **Создана:** 2026-09-23
- **Зависимости:** нет
- **Цена:** major

## Контекст

Замер 2026-09-23 на одноразовых клонах двух потребителей после `upgrade` до v0.10.0, `fold` без номера, код 0 в обоих: у первого (771 закрытая задача) 66 строк журнала получили дату свёртки `2026-09-23` вместо даты закрытия и 461 строка — исход `—`; у второго (310 задач) — 28 и 42. Тела задач в истории целы, `show N` их отдаёт (код 0), но после свёртки журнал — единственная запись в дереве, и его строки врут.

Причина — `lib/log.js`. `dateFromResult` берёт первую дату первого абзаца, а `firstParagraph` отбрасывает строки заголовка: дата в заголовке `# BL-005 — результат (снята с плана 2026-08-13)` не видна — у 49 из 66 «сегодняшних» строк первого потребителя дата стоит только там. `OUTCOME_FORMS` знают «выполнена/отклонена/слита в» и английские пары, а основная форма первого абзаца в старых архивах — `**Закрыта 2026-08-30.** Run 0830c, worker sync-doctor; ревью xhigh.` без слова исхода; английские `**Closed 2026-09-05.** Done.`, `**Исход:** закрыта.`, `**Outcome:** completed — …` (исход есть, даты нет → сегодняшняя) и проза `**Closed as dead weight removed, not as a defect fixed.**`.

BS-67.1 (minor) видит ту же дыру на 6 записях из 77 собственного архива; у потребителя это 461 из 771.

## Что сделать

- `dateFromResult` читает дату и из заголовка `result.md` — форма `(<исход> ГГГГ-ММ-ДД)`, — и из первого абзаца, как сейчас; первый абзац сильнее заголовка.
- `outcomeFromResult` читает исход и из заголовка `(выполнена|отклонена|закрыта|снята с плана ДАТА)`, и из первого абзаца в формах без прежних слов: «закрыта»/«closed»/«done» без другого слова исхода → выполнена; «снята с плана»/«снята» → отклонена; слияние по-прежнему первым. Раскладку слов на три исхода журнала записать в справочник.
- Вердикты в `test/tasks.test.mjs` на перечисленных реальных формах — красные до правки, зелёные после; проба руками по правилу репозитория; `docs/reference/02-cli.md` (fold) и `01-layout.md` (журнал); CHANGELOG «Не выпущено».
- Судьбу BS-67.1 назвать в результате: закрывается этим или остаётся.

## Не входит

- Перегенерация уже свёрнутых журналов и команда для неё.
- Формы ссылок, которые свёртка не переписывает, — BS-73.
- Релиз v0.10.1 — отдельный ход владельца.

## Проверки

- `node bin/backslop.js gates` зелёный числом; новые вердикты красные на коде до правки.
- Перемер на клоне первого потребителя после правки: строк с датой свёртки — только у записей без даты вообще, исход `—` — только у записей без слова исхода; числа в результат.
