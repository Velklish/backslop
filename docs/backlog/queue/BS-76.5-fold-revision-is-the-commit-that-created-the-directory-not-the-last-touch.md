# BS-76.5 · Массовая свёртка пишет в строку ревизию коммита, где каталог задачи появился, а не последнего, тронувшего его: show N печатает черновик result.md

- **Порядок:** 190
- **Область:** [02. Команды](../../reference/02-cli.md) § `fold`
- **Создана:** 2026-09-23
- **Цена:** major
- **Зависимости:** нет

## Контекст

Находка при работе над BS-76: первая живая свёртка v0.10.1 у потребителя ati-agents (BL-708, 2026-09-23, 773 записи). `bodyRev` в `lib/fold.js` берёт ревизию строки журнала командой `git log -1 --format=%H -- <каталог>/task.md` и проверяет `cat-file -e` только для `task.md`. `task.md` последний раз трогает коммит архивации (`git mv` в `archive/`), а `result.md` дописывается и правится позже — по ревью, приёмкой, чужими заходами. Поэтому строка называет ревизию, на которой `result.md` ещё черновик или его нет вовсе, а `show N` печатает именно её.

Улика — замер worker'а BL-708 по всем 773 строкам на базе `08793024`: у 657 тело на ревизии побайтно совпадает с удалённым свёрткой; у 7 (BL-383, 514.4, 531.2, 536, 562, 600, 627.1) на ревизии нет `result.md` — `show 627.1` и `show 531.2` дают код 0 и печатают только `task.md`; у 109 `result.md` на ревизии старше базы: у 68 разница только в ссылках, у 41 — по существу (BL-108 на `dee5554a` без правок по ревью из `b9368786`, BL-130 без «точного перечня проверок» из `acceb257`, BL-127 без правок ревью `1ee71919` и `1dc3c0d6`). Справочник 01 при этом обещает «последний коммит, тронувший путь тела». У второго потребителя, promptobus (PB-248, 312 записей на базе `2895973a`): 303 тела на ревизии равны удалённым, у 9 (PB-15.7, 161.2, 161.3, 161.4, 166, 167, 203, 206, 37.3) `result.md` старше базы, у 4 из них — по существу. Оба потребителя поправили строки руками (116 и 9): ревизия — последний коммит, тронувший каталог (`git log -1 -- <каталог>/`), с побайтной сверкой тел по всем строкам.

## Что сделать

- `bodyRev`: ревизия — `git log -1 --format=%H -- <каталог>/` (весь каталог, включая `result.md` и `minor/`), существование проверять для каждого файла тела (`task.md`, `result.md`, вложения), которое свёртка удаляет; отсутствие любого — та же ветка `ABSENT`.
- После выбора ревизии — сверка: тело на ревизии побайтно равно удаляемому файлу; расхождение — отказ свёртки с именем файла, а не тихая строка (страховка на случай незакоммиченного каталога уже есть, это её продолжение).
- Справочник 01 (раздел «Архив») и 02 (`fold`): «последний коммит, тронувший каталог тела»; CHANGELOG.

## Не входит

- Перегенерация журналов у потребителей — поправлены руками (BL-708, PB-248).
- Исход и дата строки — BS-76.3, BS-76.4, BS-76.1.

## Проверки

- `test/tasks.test.mjs` или `test/fold.test.mjs`: репозиторий, где `result.md` дописан коммитом после архивации, — строка журнала называет второй коммит, `show N` печатает дописанный результат; каталог с правкой `result.md` без коммита — отказ (уже есть) не меняется.
- Мутационная проба: вернуть `-- <каталог>/task.md` → вердикт краснеет; код и счёт в `result.md`.
- `node bin/backslop.js gates` → «гейтов 2, зелёных 2»; перемер функцией на снимке архива ati-agents (773 записи): ревизий с побайтно верным телом 773/773.
