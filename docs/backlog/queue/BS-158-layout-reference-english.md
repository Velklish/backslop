## Context

All evidence below was taken at commit 6f6318e (v0.11.0), where `node bin/backslop.js lint` exits 0. `<repo>` is the backslop checkout; throwaway projects are made with `git init -q p && cd p && node <repo>/bin/backslop.js init`.

docs/reference/01-layout.md (47,309 bytes, 142 lines) is the reference for what `init` lays down, `backslop.json`, the task file, minor entries, the archive and its journal, ADRs and templates. It is in Russian (`head -1` prints `# 01. Раскладка и форматы`); the target language of every repo doc is English. The file keeps its name: task Scope fields link to `../../reference/01-layout.md`. Tests use the name only in their own fixtures (`grep -rn "01-layout" test/*.mjs`: test/seed.test.mjs:82, test/commands.test.mjs:820/879/896/1148 write fixture files), so no test reads the real file's text.

The cards that removed the pre-0.9.0 legacy (the `Area` alias, legacy `tools` inference, the 0.9.0 migration), made adapter ownership marker-only and removed ROADMAP.md from the layout ran before this card, and the ADR consolidation cards dropped the ADR citations they owned; describe the code as it is when you start.
