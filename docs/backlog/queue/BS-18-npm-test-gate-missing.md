# BS-18 · `gates` в `backslop.json` самого backslop не включает `npm test`, хотя `AGENTS.md:7` прямо требует его гейтом — шаг 4 своей же генерируемой процедуры прогоняет только `lint`

- **Порядок:** 80
- **Область:** `backslop.json`, `AGENTS.md`, [01-layout](../../reference/01-layout.md)
- **Создана:** 2026-09-06
- **Зависимости:** нет

## Контекст

`backslop.json:4-6` (self-host конфиг репозитория backslop):
```json
"gates": [
  "node bin/backslop.js lint"
]
```
Только `lint`. `AGENTS.md:7`: «Гейты: `npm test` и `node bin/backslop.js lint` зелёные.» Генерируемый блок `<!-- backslop:start -->`, шаг 4 процедуры, `AGENTS.md:25`: «Команды из `gates` в `backslop.json` зелёные» — единственный машиночитаемый список для этого шага, и это ровно поле, где `npm test` отсутствует. `docs/reference/01-layout.md:36` подтверждает, что скиллы читают именно это поле: «`gates` … команды, которые должны быть зелёными до сдачи; скиллы говорят «прогони гейты из конфига»».

`lib/lint.js` тестов не запускает (в нём нет `exec`/`spawn`/вызова тестового раннера) — `lint` не покрывает то, что покрывает `npm test`. Дефолт `gates` для НОВОГО проекта (`lib/config.js:26`, `defaults()`, и `:99` дефолт при отсутствии поля) одинаково не включает `npm test` — это осознанный нейтральный дизайн для внешних потребителей, не у каждого проекта есть npm-тесты, и он вне этой находки: дефект в том, что self-host репозиторий backslop не подстроил СВОЙ `backslop.json` под то, что его же `AGENTS.md:7` уже объявляет.

`git log -p --follow -- backslop.json` (по истории `gates`) показывает, что поле содержало только `lint` с версии 0.2.0 (задача [BS-4](../../archive/BS-4-upgrade-and-pin/task.md), заведшей `gates`) — расхождение с текстом `AGENTS.md:7` не регрессия, а исходный недосмотр при заведении self-host конфига. В `docs/backlog` и `docs/archive` задачи на этот пункт нет.

## Что сделать

- `backslop.json:4-6` — добавить `"npm test"` вторым элементом массива `gates`, после `"node bin/backslop.js lint"`
- Дефолт `gates` в `lib/config.js` (`defaults()` и fallback при отсутствии поля) не трогать — это чужой контракт для сторонних проектов, а не self-host

## Не входит

- Дефолтное значение `gates` для новых проектов (`lib/config.js`) — не у каждого потребителя backslop есть `npm test`, менять нейтральный дизайн не нужно
- Автоматизация исполнения `gates` (см. отдельную находку о раннере) — эта задача только чинит СОСТАВ self-host списка

## Проверки

- `cat backslop.json` — `gates` содержит оба элемента: `node bin/backslop.js lint` и `npm test`
- Прогон каждой команды из обновлённого `gates` по отдельности — обе завершаются кодом 0 на чистом дереве
- `node bin/backslop.js lint` — по-прежнему `✔ lint: ошибок нет` (правка не меняет поведение самого `lint`)
