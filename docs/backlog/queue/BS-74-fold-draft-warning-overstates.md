# BS-74 · Свёртка требует заготовку в коммите даже там, где тело достижимо по записанной ревизии

- **Порядок:** 160
- **Область:** [свёртка архива](../../reference/02-cli.md)
- **Создана:** 2026-09-22
- **Зависимости:** нет

## Контекст

Находка первого боевого применения `fold N` (приёмка BS-30 и BS-67, 2026-09-22). Цена minor.

`fold N` печатает на stderr: «заготовка сообщения коммита — в stdout: закоммить свёртку вместе с ней, **иначе тело задачи потеряется**». Утверждение безусловное, а истинно оно только тогда, когда ревизии с телом нет.

Замер на приёмке этого захода. Каталоги задач закоммичены ходом `archive N` (коммит `bef8bbe`), затем `fold 30` и `fold 67`; обе строки журнала записали ревизию `bef8bbe38a`. Свёртка закоммичена **без** заготовки. После этого:

```
node bin/backslop.js show 30   → код 0, 54 строки, постановка и результат целиком
node bin/backslop.js show 67   → код 0, 59 строк, постановка и результат целиком
```

Тело достаётся `git show <rev>:./<путь>` из записанной ревизии, и заготовка ему не нужна. То есть предписание требует положить в сообщение коммита 57 строк, дублирующих то, что уже лежит в истории, а причина этого требования названа неверно.

Команда знает, в каком она случае: ревизию она сама и записала в строку журнала. Значит и сказать может по-разному.

## Что сделать

- Различать два случая в тексте на stderr: ревизия записана — заготовка не обязательна, тело достаётся `show N`; ревизии нет (`—` в поле коммита) — заготовка единственное хранилище, и это надо сказать прежней силой.
- Проверить ту же формулировку в справочнике, в правилах бэклога и в шаге 5 блока `AGENTS.md`: обязательность коммита с заготовкой записана там же и с той же безусловностью.

## Не входит

- Печать заготовки как таковая: она полезна и в случае с ревизией — даёт тело в сообщении без обращения к `show`.
- Поведение массовой свёртки: у неё причины пустой ревизии разведены отдельно, это ADR-026.

## Проверки

- Задача, тело которой закоммичено до свёртки: stderr не требует заготовку и называет `show N`; `show N` печатает тело.
- Задача без ревизии с телом: stderr требует заготовку прежней силой.
- Красная проба на каждую из двух формулировок.
- `node bin/backslop.js gates` зелёный.
