# BS-22 · Слияние CHANGELOG при приёмке track'а агент делает вручную из двух редакций — хотя разбор пунктов и секций для этого уже есть в коде backslop

- **Порядок:** 260
- **Область:** `lib/changelog.js`, `lib/lint.js`, `bin/backslop.js`, `templates/skills/backslop-batch/SKILL.md`, `templates/en/skills/backslop-batch/SKILL.md`, [reference/02](../../reference/02-cli.md)
- **Создана:** 2026-09-06
- **Зависимости:** нет

## Контекст

Правило слияния CHANGELOG сегодня — только проза скилла: templates/skills/backslop-batch/SKILL.md:104 (и англ. templates/en/…:104) — «CHANGELOG — объединение пунктов по заголовку `- **…**`: записи обеих сторон остаются; совпавший заголовок — правка одной записи, не две… вставляй только в секцию невыпущенного». В потребителе это разворачивается в ручную процедуру: репозиторий ati-agents ведёт свой локальный (не генерируемый backslop) скилл `.claude/skills/backlog-batch/SKILL.md`, и его строка 108 подтверждена сегодня дословно: «Маркеры конфликта руками не разбирай — файл собирается из двух редакций (`BL-458`): `git show HEAD:CHANGELOG.md` и `git show <голова worker'а>:CHANGELOG.md`… Конфликт здесь не исключение, а норма: в run 2026-09-02 он был на 1 из 3 задач track'а store и на 1 из 2 track'а linux».

Инструмента нет: `node bin/backslop.js help` (backslop v0.4.0) перечисляет init/new/mv/archive/adr/status/lint/upgrade/migrate/changelog/version/help — команды слияния среди них нет. `changelog` (lib/changelog.js) — только выжимка CHANGELOG самого backslop между версиями (`changelogSince`/`changelogSections`), к слиянию рабочих редакций отношения не имеет. Разбор, из которого команду можно собрать, уже написан: `CHANGELOG_ENTRY = /^- \*\*(.+?)\*\*/` (lib/lint.js:22) и `changelogSections` (lib/changelog.js:13-25).

Цена ручного порядка задокументирована в архиве: docs/archive/BS-12-batch-shared-files-merge-rule/task.md — заход 2026-09-05 (15 track'ов, 33 задачи), где стратегия `-X theirs`/`-X ours` дважды теряла hunk'и соседнего track'а и один раз продублировала хвост файла; спас самописный одноразовый скрипт, возвращавший пункты CHANGELOG по заголовку. Раздел «Не входит» самой BS-12 (строка 19) прямо называет «Инструмент слияния в CLI» — вынесенным за рамки той задачи, не отклонённым как идея.

Границы, которые новая команда обязана учесть: в CHANGELOG.md ati-agents внутри «Не выпущено» есть третий уровень — жирные подгруппы (`**Для пользователя workspace:**` и т.п., строки 5-14), под `CHANGELOG_ENTRY` не подпадающие; без базы слияния (merge-base) запись, снятую одной стороной, от записи, которой у неё никогда не было, не отличить.

## Что сделать

- Команда `backslop merge-changelog --ours <ref> --theirs <ref> [--base <ref>] [--out <файл>]` в lib/changelog.js поверх готовых разборов (`CHANGELOG_ENTRY`, `changelogSections`).
- Правила: сливать только первую секцию невыпущенного; сохранять принадлежность записи жирной подгруппе и порядок подгрупп; записи обеих сторон остаются; совпавший заголовок при одинаковом теле — одна запись; при разошедшихся телах — обе оставлены помеченными для решения агентом; с `--base` запись, снятую стороной относительно базы, — снять, без него — сохранить с пометкой.
- Вывод: число записей с каждой стороны и список помеченных пар.
- templates/skills/backslop-batch/SKILL.md и templates/en/…: заменить ручную процедуру на вызов команды (lint держит равенство шаблонов ru/en).
- Строка команды в docs/reference/02-cli.md и в `help`.
- CHANGELOG-запись backslop.

## Не входит

- Git merge driver и `.gitattributes` — требует ещё `git config merge.<driver>.driver` в каждом клоне ради того же результата, который даёт обычная команда.
- Слияние документов по `###`-секциям и списков в коде (справочник, README, регэксп-списки) — их BS-12 уже покрывает ручным правилом; здесь только CHANGELOG.
- Автоматический выбор победившего тела при расхождении записи с одним заголовком — команда только помечает пару, решение остаётся за агентом.

## Проверки

- Фикстура: два CHANGELOG.md (ours/theirs) с непересекающимися записями, одной совпавшей записью с одинаковым телом и жирной подгруппой — `node bin/backslop.js merge-changelog` даёт ожидаемый единый файл.
- `node bin/backslop.js lint` зелёный (гейт 7 — без дублей заголовков в результате слияния).
- Шаблоны ru/en скилла backslop-batch остаются равны (проверка равенства шаблонов в `lint`).
