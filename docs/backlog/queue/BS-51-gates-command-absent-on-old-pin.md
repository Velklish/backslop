# BS-51 · Блок Definition of Done брифа зовёт `gates`, которой в пинованной версии проекта нет

- **Порядок:** 10
- **Область:** генератор брифа (`brief`), блок Definition of Done; `docs/backlog/README.md`
- **Создана:** 2026-09-12
- **Зависимости:** нет

## Контекст

`backslop brief` печатает worker'у блок Definition of Done, и в нём стоит: «Project gates are green by count: `npx …backslop@<пин> gates` prints the summary “gates N, green N”». Команду `gates` генератор подставляет всегда, а строку команды собирает из версии, пинованной проектом. В проекте, пинованном на версию без этой команды, требование неисполнимо.

**Замер, дважды на одном репозитории.** `external/promptobus`, `backslop.json` пинит `0.4.0`:

```
$ npx github:Velklish/backslop#v0.4.0 gates > out; echo $?
1
✖ unknown command "gates"; see backslop help
```

`help` этой версии перечисляет `init, new, mv, archive, adr, status, lint, upgrade, migrate, changelog, version, help` — раннера гейтов нет. Ключ `gates` в `backslop.json` при этом есть и несёт три команды: `npm test`, `backslop lint`, `npm run audit`. То есть на этом пине ключ — декларация, которую CLI не исполняет.

**Оба раза worker обошёл одинаково и правильно:** прогнал три команды из ключа по отдельности, с кодом возврата у каждой, и отказался печатать сводку «гейтов N, зелёных N», которой не было. Второй добавил довод, которого не хватало первому: выдуманная сводка хуже отсутствующей, потому что выглядит как гейт.

**Цена сегодня — не сломанный прогон, а потраченный ход и подорванное доверие к блоку.** Worker упирается в неисполнимое требование, тратит ход на разбор и приходит к оркестратору с вопросом, который к его задаче отношения не имеет. Первый раз это случилось 2026-09-11 в прогоне 0911e, второй — 2026-09-12 в 0912a, на том же репозитории и с тем же выводом.

## Что сделать

- Печатать шаг гейтов по тому, что пинованная версия умеет: есть команда — звать её; нет — перечислить команды из ключа `gates` прямо в блоке, с требованием кода возврата у каждой.
- Либо, если блок обязан оставаться одинаковым для всех версий, — назвать в нём оба маршрута и условие выбора, чтобы worker не выяснял это сам.
- Проверить остальные команды, которые блок называет безусловно: та же проверка нужна каждой, которая появилась позже самой ранней поддерживаемой версии.

## Не входит

- Поднимать пин проекта: версию выбирает владелец репозитория, и `AGENTS.md` промптобуса прямо говорит обновляться по своему решению, а не по чужому коммиту.
- Сам раннер гейтов и его сводка.

## Проверки

- Бриф, собранный в проекте на версии без `gates`, называет исполнимый шаг.
- Бриф, собранный на версии с `gates`, по-прежнему зовёт команду.
