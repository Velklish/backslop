# BS-50 · `new --parent` не принимает дробный номер родителя, а находка под закрытой задачей валит `lint` в triage

- **Область:** `new`, `lint` (находки в `triage/`)
- **Создана:** 2026-09-10, постановка из репозитория-потребителя (ati-agents, run 0910a, BL-540.1)
- **Зависимости:** нет

## Контекст

Worker закрывал `BL-540.1` (находка под `BL-540`, уже закрытой) и по решению approver'а заводил вторую половину развилки находкой с родителем. Две грабли подряд, обе в v0.6.0:

1. `new <slug> --parent 540.1` отказывает: «`--parent` ждёт N без точки». Родителем находки не может быть находка — а в потребителе это штатный случай: `BL-540.1` сама порождает `BL-540.1.x`-класс вопросов, и единственный выход — вешать на прародителя.
2. `new <slug> --parent 540` проходит (файл `BL-540.3-…` в `triage/`), но следующий `lint` красный: «находка BL-540.3 лежит в triage/, а задача BL-540 закрыта — разбери её». Разбор — ход approver'а, а не worker'а; worker'у остаётся либо оставить репозиторий с красным гейтом, либо завести карточку без родителя и связь описать словами (так и сделано: `BL-629` без `--parent`).

Итог: связь «находка ↔ закрытая задача» инструмент выразить не даёт, и history теряет ребро, ради которого `--parent` и заведён.

## Что сделать

- `--parent` принимает дробный номер (`N.M`): нумерация ребёнка — `N.M.1`, либо, если трёхуровневые номера не нужны по решению владельца, ребёнок получает следующий свободный `N.k` с полем «Родитель: N.M» в шапке.
- Находка под закрытым родителем в `triage/` не красит `lint` сама по себе: красным остаётся только случай, когда карточка лежит в `triage/` дольше порога разбора (или вовсе не красит — решить). Текст ошибки, если остаётся, называет, чей это ход: «разбери её (approver)».
- В справочнике `new`/`lint` назвать оба случая.

## Не входит

- Ретроактивная перенумерация уже заведённых карточек в потребителях.

## Проверки

- `new x --parent N.M` создаёт карточку и `lint` зелёный.
- `new x --parent N` при закрытой (архивной) задаче N создаёт карточку в `triage/`, `lint` зелёный (или красный с текстом, называющим ход approver'а — по принятому решению).
- Существующие пробы `new`/`lint` зелёные.
