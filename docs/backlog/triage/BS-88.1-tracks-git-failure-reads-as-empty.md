# BS-88.1 · tracks: a failed git call outside pendingCommits reads as 'no repository' or 'no branches'

- **Scope:** [02. CLI](../../reference/02-cli.md) § tracks
- **Created:** 2026-09-25
- **Dependencies:** none

## Context

Finding discovered while working on BS-88. Cost: major — `tracks` can report no run branches while one carries unmerged task commits. Verified on the BS-88 branch (51e52c2) with a git shim on PATH that `kill -9`s itself when a given argument is present.

Evidence:

- Branch `side` with an unmerged `BS-7: side work` commit. Real git: `tracks` → `side … task commits not in HEAD: 1`, `✔ tracks: worktrees and branches 1, not merged 1`, rc=0. Shim killing `for-each-ref`: `✔ tracks: worktrees and branches 0, not merged 0`, rc=0 — the branch is gone and nothing says so. Cause: `localBranches` turns any failure into an empty list:

<!-- quote:../../../lib/tracks.js -->
```js
function localBranches(root) {
  const r = git(root, ['for-each-ref', '--format=%(refname:short)', 'refs/heads/']);
  if (r.status !== 0) return [];
```
<!-- /quote -->

- Shim killing `--show-toplevel`: `tracks` → `✖ there is no git repository: worktrees and run branches cannot be listed`, rc=1. The refusal is right, the cause is wrong: a killed git is reported as a missing repository. Cause:

<!-- quote:../../../lib/tracks.js -->
```js
  const top = git(root, ['rev-parse', '--show-toplevel']);
  if (top.status !== 0) {
```
<!-- /quote -->

BS-88 fixed the same class in `pendingCommits`, `worktrees()` and `foreignTaskIds`; its boundary left `localBranches` and this check untouched. Not checked: `git branch --show-current` failing (`currentBranch` becomes empty, and the current branch would be listed as a track) — an assumption from the code, not reproduced.

## Work to do

- `localBranches`: refuse with `gitCause` on a failed `for-each-ref` instead of returning an empty list.
- The toplevel check: say "no repository" only when `insideRepo` (lib/util.js) returns false; otherwise refuse with `gitCause`.

## Out of scope

- Prunable worktrees — the BS-102 card.

## Verification

- Shim test in test/tracks.test.mjs: `for-each-ref` killed → rc=1 with the git cause, not an empty listing; `--show-toplevel` killed → rc=1 with the git cause, not `there is no git repository`.
- `npm test` → rc=0; `node bin/backslop.js lint` → rc=0.
