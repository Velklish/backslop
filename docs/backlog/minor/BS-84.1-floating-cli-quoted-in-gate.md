# BS-84.1 · floating-cli-quoted-in-gate

- **Scope:** [02. CLI](../../reference/02-cli.md)
- **Created:** 2026-09-25
- **Parent:** BS-84
- **Cost:** minor

## Evidence

Finding discovered while working on BS-84.

Evidence: At 5897495: rewriteCommand('sh -c "npx github:me/proj lint"', 'npx github:me/proj', parseCli('npx github:me/proj'), '0.11.0') returns the command unchanged, while an unquoted 'npx github:me/proj lint' becomes 'npx github:me/proj#v0.11.0 lint' (node -e run in the worktree). A floating cli is matched as a whole word bounded by whitespace or ; & | ( ), so a quote before it leaves the gate floating after upgrade pins cli; lint does not flag a floating form inside gates. Pinned forms are unaffected (pinRe).
