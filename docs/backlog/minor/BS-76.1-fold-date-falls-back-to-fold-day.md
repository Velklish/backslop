# BS-76.1 · Свёртка ставит дату свёртки записи, у которой в result.md нет даты закрытия, хотя дата лежит в истории

- **Область:** [02. Команды](../../reference/02-cli.md) § `fold`
- **Создана:** 2026-09-23
- **Родитель:** BS-76
- **Цена:** minor

## Улика

Находка при работе над BS-76.

Улика: Замер 2026-09-23 после правки BS-76 на тех же result.md, что свернул v0.10.0 (git archive HEAD docs/archive потребителей: ati-agents f6ff0c22, promptobus 9692b10c): у первого 17 из 771 записей без даты ни в первом абзаце, ни в скобках заголовка (BL-138, BL-151, BL-154, BL-155, BL-544.1, BL-549.1, BL-651 …), у второго 27 из 310 (PB-166.1, PB-29.1, PB-35, PB-169 …) — строка журнала получает дату свёртки (lib/fold.js: dateFromResult(resultText) ?? today()). У 9 из 44 в теле result.md есть другие даты — решение владельца, замер (BL-550: «замером оркестратора 2026-09-06»), и читать их датой закрытия нельзя. Предположение, не проверено: дату закрытия отдаёт история — коммит, переносивший каталог в archive/ (archive N — это git mv).

Предложение (свёртка у потребителей 2026-09-23): дата закрытия без даты в `result.md` — дата коммита ревизии тела (`git log -1 --format=%cs <rev>`), а не день свёртки; у promptobus это 27 из 30 строк с датой свёртки, у ati-agents — 17 из 19.
