# BS-92.1 · CHANGELOG entry title stops at a literal ** inside a code span

- **Scope:** [03. lint](../../reference/03-lint.md) § gate 7
- **Created:** 2026-09-25
- **Parent:** BS-92
- **Cost:** minor

## Evidence

Finding discovered while working on BS-92.

Evidence: lib/lint.js:29 CHANGELOG_ENTRY = /^- \*\*(.+?)\*\*/ is lazy, so the title of '- **`gates` `when`: `**/` inside a segment …**' reads as '`gates` `when`: `'. Seen in the merge-changelog report while merging main into the git-b branch (8804f94): 'only in ours: `gates` `when`: `'. Both the lint gate 7 uniqueness check (lib/lint.js:560) and merge-changelog entryKey (lib/merge-changelog.js:169) key on this, so two titles sharing such a prefix would be taken as one entry. Assumption, not reproduced as a collision. Worked around by rewording the BS-92 entry title.
