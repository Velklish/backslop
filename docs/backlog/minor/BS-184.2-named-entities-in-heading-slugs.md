# BS-184.2 · Heading slugs keep the letters of a named entity other than six

- **Scope:** [03. Lint](../../reference/03-lint.md)
- **Created:** 2026-09-30
- **Parent:** BS-184
- **Cost:** minor

## Evidence

Finding discovered while working on BS-184.

Evidence: measured 2026-09-30 with `glab api --hostname gitlab.ati.st -X POST markdown -f text=... -f gfm=true`: `## A &mdash; B` gets id `a--b` and `## Copy &copy; x &hellip; y` gets `copy--x--y`; `anchorsOf` in lib/links.js gives `a-mdash-b` and `copy-copy-x-hellip-y`, because `renderedProse` decodes only `&amp;`, `&lt;`, `&gt;`, `&quot;`, `&apos;`, `&nbsp;` and numeric references. A link written against the rendered id (`#a--b`) is reported as a missing anchor. A letter entity such as `&eacute;` would need the opposite (keep the letter), so dropping unknown entities is not a fix; the full HTML5 table is not vendored (no dependencies).
