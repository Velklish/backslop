## Улика

Находка при работе над BS-75.

Улика: test/comment-scan.mjs, longBlocks: блок судится только по `r.end - r.start + 1 > limit`, ширина строки не считается. Замер на 5e5554a по git ls-files lib test bin scripts (.js/.mjs): 31 строка комментария шире 100 знаков, самая широкая — 124, lib/show.js:44. ADR-028, раздел «Чего гейт не ловит», этот обход не называет, а соседний (пустая строка рвёт блок) называет. Свод BS-75 держал строки не шире 100 знаков по привычке файла, не по гейту.
