# BS-78.4 · gates печатает «не запустился» у гейта, который отработал кодом 0 и посчитан зелёным

- **Область:** [02. Команды](../../reference/02-cli.md) § `gates`
- **Создана:** 2026-09-24
- **Родитель:** BS-78.2
- **Цена:** minor

## Улика

Находка при работе над BS-78.2.

Улика: Замер 2026-09-24 на 0c93402, прогон node bin/backslop.js gates --keep-going с паузой машины посередине: строка гейта — «✔ npm test — не запустился: spawnSync /bin/sh ETIMEDOUT, 1579674 ms», итог «гейтов 2, зелёных 1», при этом node --test напечатал tests 445, pass 445, fail 0. runGate (lib/gates.js:138-153) пишет code = r.status и error = r.error.message, outcome (lib/gates.js:156-160) проверяет error раньше code, а зелёный считается по коду. Предположение о механизме: spawnSync вернул status 0 вместе с error ETIMEDOUT — таймер потолка 10 минут сработал по настенным часам после сна машины, когда npm test уже вышел. Повторный прогон без паузы — «✔ npm test — код 0, 40943 ms». Отчёт противоречит сам себе: значок и счёт — зелёный, текст — незапуск.
