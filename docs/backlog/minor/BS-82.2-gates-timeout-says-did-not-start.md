# BS-82.2 · gates называет ETIMEDOUT потолка «не запустился», хотя гейт запускался и шёл до потолка

- **Область:** [02. Команды](../../reference/02-cli.md) § `gates`
- **Создана:** 2026-09-24
- **Родитель:** BS-82
- **Цена:** minor

## Улика

Находка при работе над BS-82.

Улика: Стенд вердикта «gates: гейт с ошибкой запуска при коде 0 — не зелёный, итог и код возврата красные» (test/gates.test.mjs, ce3b14b): гейт trap 'exit 0' TERM под потолком 300 мс печатает «✖ trap … — не запустился: spawnSync /bin/sh ETIMEDOUT, 3xx ms». outcome() в lib/gates.js проверяет сигнал раньше error, и error без сигнала называет «не запустился» / «did not start» — в том числе ETIMEDOUT потолка у оболочки, пережившей SIGTERM; ETIMEDOUT значит, что команда запускалась и пережила потолок. Текст причины BS-82 оставила прежним по брифу; отдельное слово для потолка — развилка контракта вывода gates (ADR-009 различает три исхода).
