## Evidence

Finding discovered while working on BS-43.

Evidence: Hypothesis, not reproduced, read not probed (review of the minor batch on a4a4f69): when a symlinked alias of a status or archive directory is listed first by the link walk (e.g. 'aa-alias -> docs/backlog'), relocateTask in lib/tasks.js resolves the links of a file reached through the alias against path.posix.dirname(rel) = 'aa-alias/queue', so a link of a card reached only through the alias may resolve to something other than task.rel and stay unrewritten without any message. The crash on the moved path was fixed in the batch (a listed file that no longer exists is skipped); this silent case was not measured. A probe would put a card with a relative link to the moved card behind an alias that is not also listed under its real path.
