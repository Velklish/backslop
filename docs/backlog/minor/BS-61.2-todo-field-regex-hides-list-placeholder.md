# BS-61.2 · lint не видит заглушку «- [TODO: …]» в списке: TODO_FIELD читает «[TODO» как имя поля

- **Область:** 
- **Создана:** 2026-09-19
- **Родитель:** BS-61
- **Цена:** minor

## Улика

Находка при разборе бэклога aivals 2026-09-19 после `upgrade` на v0.9.0. В `lib/lint.js` `isTodoPlaceholder` сначала проверяет строку целиком по `TODO_VALUE`, затем снимает поле по `TODO_FIELD` — а `[^:
]+:` в нём принимает за имя поля и `- [TODO`: значение становится `ход назначается при разборе triage]`, и `TODO_VALUE` его не узнаёт. Замер: в `docs/backlog/queue/` aivals 235 строк `- [TODO: ход назначается при разборе triage]` и 340 строк `- [TODO]`; `lint` красит ровно 340. Ту же строку пишет собственный шаблон `task.md` в раздел «Что сделать», так что карточка в `queue/` с нетронутой заготовкой хода проходит гейт. Правка — снимать маркер списка до разбора поля либо не считать `[TODO` именем поля; красная проба — `- [TODO: текст]` в `queue/`.
