## Улика

Находка при работе над BS-78.

Улика: Прогон вердикта «show N: тело из сообщения коммита печатается без диффа…» (test/fold.test.mjs) на lib/show.js и lib/util.js коммита c2ee9bc (до BS-78) в ветке worktree-promptobus-bs-0924-bs76-t20260924-115051: код 1, stderr «✖ git show 2f7932b2…: код null — коммит из строки docs/archive/LOG.md в этом клоне не читается». spawnSync вернул status null и пустой stderr, причина (ENOBUFS) лежит в r.error, а сообщение lib/show.js:69-71 его не читает; у потребителя PB-248 тот же текст «git show e93083d7: exit code null» (карточка BS-78). После BS-78 потолок вывода 256 МиБ. Предположения, не проверены: timeout 60 с в git() даёт тот же status null; gitOrFail в lib/util.js r.error уже читает — сообщения в show.js и fold.js (git rm) могли бы брать причину оттуда же.
