- **Родитель:** BS-76
- **Цена:** minor

## Улика

Находка при работе над BS-76.

Улика: Живая свёртка v0.10.1 в promptobus (312 записей, 2026-09-23): worker PB-248 насчитал 61 инверсию дат между соседними строками LOG.md — строки идут по номеру задачи, а шапка журнала говорит «в порядке закрытия». У 27 строк с датой свёртки настоящая дата закрытия доступна как дата коммита ревизии тела (2026-09-06 для PB-29.1…40, 2026-09-12 для PB-95…186) — тот же источник закрыл бы и BS-76.1.
