- **Parent:** BS-247
- **Cost:** minor

## Context

Audit finding PQA-010. `docs/reference/06-module-map.md:83` lists missing export CHANGELOG_ENTRY among Key exports; `docs/adr/adr-043-changelog-merge.md:23` also uses that old name. Current `lib/changelog-format.js:9` exports `entryTitle`, and lib/lint.js:21 / lib/merge-changelog.js:6 import it. The helper handles title parsing and code spans; there is no reason to restore an obsolete regex/export merely to match the documents.

Audit snapshot: `44e74a32ff6a6b6c946321b3614b1881a2ccedfe`. Commands below ran from the Backslop repository root unless another cwd is stated. On that unchanged snapshot, `node bin/backslop.js gates` exited 0: gates 2/2, tests 1240/1240, failures 0, skipped 0. This is a pre-change baseline; all implementation and post-fix checks below are notRun.

## Work to do

- Replace the old helper name in both current normative documents with entryTitle while preserving ADR rationale and parser behavior.
- Add an assertion in existing test/doc-facts.test.mjs that each explicitly documented identifier in the module-map Key exports column exists in the corresponding module namespace. The existing lib file-count assertion (:13) does not verify API names.
- Keep the guard read-only; if any import has side effects, inspect that module's static export declaration instead of invoking run. Failure should name module-map path/line and missing identifier.
- The column promises selected Key exports, not every export: do not require full namespace equality or documenting private helpers.

## Out of scope

No runtime exports/API, migration/parser changes, new complete export registry, blanket import execution or unrelated module-map cleanup.
