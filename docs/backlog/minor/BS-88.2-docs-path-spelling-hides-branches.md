# BS-88.2 · new: docs spelled ./docs in backslop.json hides numbers on other branches

- **Created:** 2026-09-25
- **Parent:** BS-88
- **Cost:** minor

## Evidence

Finding discovered while working on BS-88.

Evidence: backslop.json edited by hand to "docs": "./docs" (init --dir ./docs normalizes to docs, lib/init.js:69; loadProject does not normalize), BS-1 on main, BS-2 committed only on branch worker: node bin/backslop.js new c on main -> '✔ BS-2: docs/backlog/triage/BS-2-c.md', rc=0, no 'is taken' line — a duplicate. Cause: foreignTaskIds keeps ls-tree lines that start with cfg.docs + '/', and git prints docs/backlog/... without the ./ prefix. Measured on 51e52c2 (BS-88 branch); the same run on main 6f5a2a7 (before BS-88) also gives BS-2, so this is not a regression.
