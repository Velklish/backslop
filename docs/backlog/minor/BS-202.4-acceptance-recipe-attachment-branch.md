# BS-202.4 · The acceptance recipe has no branch for a task directory that holds attachments

- **Scope:** [Reference index](../../reference/README.md)
- **Created:** 2026-10-02
- **Parent:** BS-202
- **Cost:** minor

## Evidence

Finding discovered while working on BS-202.

Evidence: Hypothesis, not reproduced end to end: step 5 of the AGENTS block forbids a commit between archive N and fold N, and fold N refuses while an attachment is missing from HEAD. A task directory exists only from archive N on, so an attachment the approver adds there can reach HEAD only through that forbidden commit; the refusal now says to move the files out of the directory. Whether the recipe should instead get an attachment branch (commit the directory, fold, keep that commit out of the squash) is the owner's decision; sources: lib/fold.js prepare, templates/en/agents-section.md step 5, docs/reference/02-cli.md § fold.
