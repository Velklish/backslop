# BS-64.3 · mv N minor не приносит раздел «Улика», а lint его в minor/ не требует: вторая дверь мимо правила улики

- **Область:** [02. Команды](../../reference/02-cli.md) § `mv`
- **Создана:** 2026-09-23
- **Родитель:** BS-64
- **Цена:** minor

## Улика

Находка при работе над BS-64.

Улика: Замер worker'а BL-709 (ati-agents, backslop v0.10.0, 2026-09-23): «mv 704 minor» → код 0, дописаны только «Цена: minor» и «Прежний порядок», grep -c '^## Улика' → 0; «backslop lint» на этом состоянии → код 0. «new --minor» без --evidence отказывает (BS-64.1), а «mv N minor» кладёт карточку в minor/ без улики, и гейт молчит — правило улики держится только дисциплиной. Родственно BS-64.2 (mv N.k minor приносит форму task.md).
