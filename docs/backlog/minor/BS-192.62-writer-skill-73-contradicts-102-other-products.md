- **Created:** 2026-10-02

- **Cost:** minor

## Evidence

Finding discovered while working on BS-192.

Evidence: templates/en/skills/backslop-writer/SKILL.md:73 says that a statement a document makes that the code cannot confirm is "a confirmed Blocking finding of the document, not a hypothesis", and :102 says that a finding the writer could not verify itself ("the command cannot be run here, the evidence is out of reach") is an assumption, filed as a `--hypothesis` entry with a cost. A statement about the behaviour of another product fits both: the code cannot confirm it, and the writer cannot run the other product. The owner's reading, applied to BS-192.46 to BS-192.61, is :102. The Russian twin at templates/skills/backslop-writer/SKILL.md:73 and :102 has the same two sentences. Nothing in either layer says which one governs a statement about another product, and no test pins either reading. Check: both layers state the rule one way (the case of another product named in :73 or :102), and a test in test/writer.test.mjs fails on the old pair of sentences.
