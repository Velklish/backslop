# BS-127.1 · Release script may not find npm on Windows

- **Scope:** [02. CLI](../../reference/02-cli.md) § release
- **Created:** 2026-09-26
- **Parent:** BS-127
- **Cost:** minor (hypothesis)

## Evidence

Finding discovered while working on BS-127.

Evidence: Unverified, not checked on Windows (no Windows machine or runner in this run). scripts/release.mjs command() spawns npm by bare name with spawnSync(bin, args) and no shell. The BS-127 card expects, on win32 with Node 20.12.2 or later: spawnSync('npm', ['--version']) gives error code ENOENT, and spawnSync('npm.cmd', ['--version']) gives EINVAL (CVE-2024-27980). Refutation check done: README.md, AGENTS.md and docs/reference/02-cli.md do not limit releasing to POSIX. Command run: `grep -n -i "posix\|windows\|win32\|cmd\.exe" README.md AGENTS.md docs/reference/02-cli.md`; hits only docs/reference/02-cli.md:20 (seed --scan quoting for cmd.exe) and :66 (posix-form paths in status --json), neither about releasing.
