# BS-193.5 · gate11-pin-in-prose-no-end-boundary

- **Scope:** [03. Lint](../../reference/03-lint.md)
- **Created:** 2026-09-29
- **Parent:** BS-193
- **Cost:** minor

## Evidence

Finding discovered while working on BS-193.

Evidence: Measured at 4d2a254: PIN_IN_PROSE in lib/lint.js (gate 11, the tool repository's own README/CHANGELOG pins) applied to 'github:Velklish/backslop#v0.1.0-rc.1' gives the version 0.1.0; the same for '#v0.1.0x' and 'backslop@0.1.0.1'. It has no end boundary, unlike pinRe in lib/config.js, which now ends at the version. Effect, presumably: gate 11 compares a suffixed pin as if it were the plain one. Suggested fix: append (?![\w-]|\.\d) to the regex; lib/lint.js is outside the BS-193 worker's bounds.
