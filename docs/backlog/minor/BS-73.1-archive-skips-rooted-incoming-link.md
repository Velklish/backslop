# BS-73.1 · archive N не переписывает корневую входящую ссылку на переехавший файл

- **Область:** [02. Команды](../../reference/02-cli.md) § `archive`
- **Создана:** 2026-09-24
- **Родитель:** BS-73
- **Цена:** minor

## Улика

Находка при работе над BS-73.

Улика: rewriteIncomingLinks идёт через mapLinks, а тот корневые пути (`/docs/…`) пропускает: для ссылок самого переехавшего файла верно, для входящих — нет. Замер 2026-09-24 на 1b11a44, временный проект: docs/ROADMAP.md с корневой ссылкой `[BS-3](/docs/backlog/active/BS-3-gamma.md)` и относительной туда же; archive 3 → код 0, относительная переписана на `archive/BS-3-gamma/task.md`, корневая осталась; lint → код 1, «битая ссылка /docs/backlog/active/BS-3-gamma.md». Та же форма, что BS-73 закрыла для fold; гейт 1 ловит.
