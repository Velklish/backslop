## Evidence

Finding discovered while working on BS-158.

Evidence: lib/init.js, the comment above checkAdapterRoots ('Pre-write phase: every read and check that can refuse runs here, before saveConfig'), overclaims: saveConfig and the docs skeleton are written before cleanupAdapters/renderAdapters, which refuse on write (a directory at an output path, a file on a path component, a symlink below the adapter root). Repro at 2b00130: git init -q p && cd p && mkdir -p .claude/skills/backslop-task/SKILL.md && node <repo>/bin/backslop.js init --tools claude gives rc=1 with the refusal 'owned adapter output is not a file: .claude/skills/backslop-task/SKILL.md' (printed in the project language, ru there) and backslop.json and docs/ already on disk; after removing the directory, a plain init gives rc=0 and 'adapter outputs: claude 7'.
