# BS-78.3 · Вердикт show N с sh-шимом git не помечен skip на Windows

- **Область:** [02. Команды](../../reference/02-cli.md) § `show`
- **Создана:** 2026-09-24
- **Родитель:** BS-78.2
- **Цена:** minor

## Улика

Находка при работе над BS-78.2.

Улика: Предположение, на Windows не проверено. test/fold.test.mjs:751 — вердикт «show N: git, оборванный на чтении сообщения, — отказ называет сигнал, а не «код null»» кладёт в PATH шим git с #!/bin/sh без { skip: process.platform === 'win32' }. Вердикты с тем же шимом из BS-81 (test/gates.test.mjs:217, test/upgrade.test.mjs:128, test/merge-changelog.test.mjs:370, test/lint.test.mjs:804) и шимы npx в test/upgrade.test.mjs помечены skip на win32. На Windows файл без расширения PATH-поиском не исполнится, возьмётся настоящий git, и вердикт, вероятно, покраснеет на коде 0 вместо 1.
