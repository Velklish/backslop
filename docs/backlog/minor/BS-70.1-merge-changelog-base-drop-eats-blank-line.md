# BS-70.1 · merge-changelog --base снимает последний блок theirs вместе с пустой строкой перед следующей секцией

- **Область:** [02. CLI](../../reference/02-cli.md)
- **Создана:** 2026-09-24
- **Родитель:** BS-70
- **Цена:** minor

## Улика

Находка при работе над BS-70.

Улика: Замер approver'а 2026-09-24: срез `git archive <sha> lib package.json | tar -x -C <tmp>`, вызов `mergeChangelog(ours, theirs, base)` из `lib/merge-changelog.js`. Стороны: ours — пустая `## Не выпущено`, за ней `## v0.1.0 — 2026-01-01`; theirs — `- **Новая** — тело`, `- **Снятая** — тело`, пустая строка, `## v0.1.0 …`; base — `- **Снятая** — тело`, пустая строка, `## v0.1.0 …`. На 757d102 и на 21f6352 — код 0, вывод побайтно один: `"# Changelog\n\n## Не выпущено\n\n- **Новая** — тело\n## v0.1.0 — 2026-01-01\n\n- **Старое** — выпущено\n"`, `report.dropped` = `["Снятая"]`. Пустая строка перед `## v0.1.0` уходит вместе со снятым по `--base` последним блоком theirs, и перед следующей секцией её нет. Поведение старше BS-70: на базе то же.
