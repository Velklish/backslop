## Улика

Находка при работе над BS-74.

Улика: Последняя строка stderr fold без номера — «закоммить свёртку вместе с ней, иначе тело задачи потеряется» — и при всех записанных ревизиях, и без --embed-missing, хотя заготовка draftMany тел не несёт. Замер 2026-09-24 на 1b11a44, временный проект: две закрытые задачи закоммичены, fold → код 0, последняя строка stderr та самая, в stdout «текст постановки» нет. BS-74 поведение массовой свёртки вывела из предмета (ADR-026).
