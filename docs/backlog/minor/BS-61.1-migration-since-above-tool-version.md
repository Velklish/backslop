# BS-61.1 · Запись MIGRATIONS с since выше версии инструмента ничем не ловится

- **Область:** [02. CLI](../../reference/02-cli.md)
- **Создана:** 2026-09-18
- **Родитель:** BS-61
- **Цена:** minor

## Улика

Находка ревью BS-61 (reviewer, 2026-09-18). Запись `MIGRATIONS` со `since` выше `TOOL_VERSION` проходит молча: `lib/migrate.js` сравнивает штамп проекта только с `since`, и до релизного бампа такая миграция печатается «должной» при каждом запуске, а отметиться применённой не может — штамп не пишется при `from === TOOL_VERSION`. Живой случай — `since: '0.9.0'` при инструменте 0.8.0 между коммитом BS-61 и бампом. Возможный ход: отказ или предупреждение `migrate`/`lint` на `since > TOOL_VERSION`.
