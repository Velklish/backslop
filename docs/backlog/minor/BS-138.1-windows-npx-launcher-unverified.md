- **Parent:** BS-138

## Evidence

Finding discovered while working on BS-138.

Evidence: No Windows machine in this run. Measured on darwin only: at f2ab032, `node --test --test-timeout=60000 --test-reporter=tap test/upgrade.test.mjs` rc 0, tests 45, pass 45, skipped 0; the full `node bin/backslop.js gates` rc 0 with 650 of 650. The win32 branch of npxShim() in test/upgrade.test.mjs writes `npx.cmd` as `@"<node>" "<dir>\npx.mjs" %*`; it never ran. Assumptions, not checked: `cmd.exe /d /s /c "npx …"` returns node's exit code through npx.cmd, whose last line is the node call, so the probe-failure table still sees ` — код 3. `; cmd.exe finds npx.cmd before the real npx through PATH order and PATHEXT; the child env keeps the test's PATH over the inherited Path key (Node sorts env keys on win32 and keeps the first, and PATH sorts before Path); the unskipped git-based tests (a pinned consumer with committed rules) behave the same under core.autocrlf. Six tests keep the win32 skip on purpose (git signal shim, time-cap trap, signal kill, two symlink tests, chmod 000); the card's figure of 2 was taken at an older commit.
