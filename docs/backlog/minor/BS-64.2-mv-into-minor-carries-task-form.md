# BS-64.2 · Вторая дверь в minor/: mv N.k minor переносит форму task.md и приносит четыре заглушки

- **Область:** 
- **Создана:** 2026-09-22
- **Родитель:** BS-64
- **Цена:** minor

## Улика

Находка при работе над BS-64.

Улика: Замер на временном проекте (init --tools none), три шага подряд, счёт только по ошибкам файлов бэклога: чистый проект → `lint` код 0, ошибок 0; `new finding --parent 1` (находка в triage/) → `lint` код 0, ошибок 0; `mv 1.1 minor` → `lint` код 1, ошибок 4. Причина: `mv N.k minor` переносит файл, не меняя его формы, а находка из triage/ собрана по `task.md` — в каталог, который судит по `minor.md`, приезжают «Улика: [TODO: путь к файлу или команда с выводом]» и три заглушки разделов постановки «Что сделать», «Не входит», «Проверки» (строки 11, 16, 20, 24). В triage/ они не красят по решению BS-64, в minor/ красят все четыре.
