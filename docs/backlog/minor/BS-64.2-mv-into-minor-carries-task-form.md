# BS-64.2 · Вторая дверь в minor/: mv N.k minor переносит форму task.md и приносит четыре заглушки

- **Область:** [02. Команды](../../reference/02-cli.md) § `mv`
- **Создана:** 2026-09-22
- **Родитель:** BS-64
- **Цена:** minor

## Улика

Находка при работе над BS-64.

Улика: Замер на временном проекте (init --tools none), три шага подряд, счёт только по ошибкам файлов бэклога: чистый проект → `lint` код 0, ошибок 0; `new finding --parent 1` (находка в triage/) → `lint` код 0, ошибок 0; `mv 1.1 minor` → `lint` код 1, ошибок 4. Причина: `mv N.k minor` переносит файл, не меняя его формы, а находка из triage/ собрана по `task.md` — в каталог, который судит по `minor.md`, приезжают «Улика: [TODO: путь к файлу или команда с выводом]» и три заглушки разделов постановки «Что сделать», «Не входит», «Проверки» (строки 11, 16, 20, 24). В triage/ они не красят по решению BS-64, в minor/ красят все четыре.

Ход выбирает владелец, три варианта.

**А. Переформовывать карточку при переезде.** `mv N.k minor` пересобирает файл по шаблону minor: «Контекст» становится «Уликой», разделы постановки отбрасываются. Дорого и теряет текст, который автор уже написал.

**Б. Требовать улику у `mv N minor`** так же, как теперь у `new --minor`: отказ до переноса, если раздел улики пуст или в заглушке. Симметрично уже принятому решению, но `mv` — команда approver'а, и отказ ляжет на того, кто находку не писал.

**В. Снять гейт заглушек с `minor/` целиком**, как BS-64 снял его с triage. Дёшево, но отменяет предмет BS-64.1: запись без улики снова станет законной.

**Решение владельца 2026-09-24:** Б с добавкой — `mv … minor` требует улику (раздел или `--evidence`), заглушки постановки снимает, написанный текст сохраняет; `lint` в `minor/` требует «Улику». Закрывается пачкой [BS-79](../queue/BS-79-minor-batch-cli-commands.md).
