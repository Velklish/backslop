# BS-25 · Гейт lint не проверяет поле «Область» карточки, поэтому BL-507 стоит в очереди без неё, а заглушка от new никем не ловится

- **Область:** [reference/01](../../reference/01-layout.md), [reference/03](../../reference/03-lint.md), `lib/lint.js`, `lib/tasks.js`, `lib/new.js`
- **Создана:** 2026-09-06
- **Зависимости:** нет
- **Взята:** 2026-09-09

## Контекст

Замер сегодня на потребителе ati-agents: живых карточек 21 (queue 15, deferred 6, active 0). `grep -L '\*\*Область:\*\*' docs/backlog/queue/*.md docs/backlog/deferred/*.md` находит ровно один файл — docs/backlog/queue/BL-507-cursor-headless-windows-os-aware-install.md: в шапке только «Порядок» и «Создана», поля «Область» нет вовсе. `node .../backslop/bin/backslop.js lint` при этом печатает «✔ lint: ошибок нет».

Поле объявлено (lib/tasks.js:10, `export const FIELD_AREA = 'area'`), но не читается ни одним гейтом — `grep -rn "FIELD_AREA" lib/ bin/ templates/` даёт только эту строку декларации; lintStatusFields (lib/lint.js:147-172) проверяет только «Порядок» в queue/, дату «Взята» в active/ и раздел «Отложено» в deferred/. Справочник восьми гейтов (docs/reference/03-lint.md) шапку карточки не упоминает вовсе.

`new` кладёт в поле заглушку `[TODO: раздел reference/]` (lib/new.js:62) — если агент забудет её заполнить, гейт этого не заметит: тот же `[TODO` в result.md архива красит гейт 5 (lib/lint.js:194), а в шапке карточки такой проверки нет.

«Зависимости» (FIELD_DEPS, lib/tasks.js:13) в той же ситуации — тоже не читается ни одним гейтом, и без неё сегодня стоит 13 из 21 живой карточки. Но обязательности этого поля не объявляет ни docs/backlog/README.md:21 («постановку, область, даты, состояние» — «Зависимости» не названы), ни docs/reference/01-layout.md:52-55 (поле показано в примере шапки без пометки «обязательно»); карточки снимают его осознанно (например BL-514, BL-517, BL-531 — есть «Область», нет «Зависимостей»). Гейт на отсутствие «Зависимостей» покрасил бы эти легитимные файлы.

## Что сделать

- lib/lint.js рядом с lintStatusFields (или отдельной функцией по тому же обходу задач вне архива): FIELD_AREA обязано присутствовать, быть непустым и не содержать [TODO (регэксп TODO уже есть, lib/lint.js:20).
- docs/reference/03-lint.md: добавить строку гейта (переименовать «Поля статусов» в «Поля», раз проверка не привязана к статусу, либо завести отдельный девятый гейт в таблице — выбор формы за исполнителем).
- CHANGELOG.md — запись о новом гейте.
- test/lint.test.mjs — мутационная проба: убрать «Область» из зелёного проекта → красный с именем файла; вернуть → зелёный; отдельная проба на оставленный [TODO: раздел reference/] от new.

## Не входит

- FIELD_DEPS («Зависимости») — поле необязательно по docs/backlog/README.md и docs/reference/01-layout.md, 13 из 21 живой карточки снимают его осознанно; гейт дал бы ложные срабатывания.
- Выбор, какой раздел reference/ является «Областью» задачи, — остаётся суждением агента; проверка только на присутствие и заполненность.

## Проверки

- На подставном проекте с удалённой «Областью» у одной задачи — lint красный, называет файл; вернуть поле — зелёный.
- node bin/backslop.js lint на живом дереве backslop (где «Область» везде на месте) остаётся зелёным.
- Задача, заведённая new <slug> --queue и не тронутая руками (заглушка [TODO: раздел reference/] осталась), красит lint.
