# BS-64 · Карточка из new в triage/ красит lint: заглушка «Области» попадает под гейт заглушек вопреки README

- **Область:** [03-lint](../../reference/03-lint.md)
- **Создана:** 2026-09-19
- **Зависимости:** нет
- **Взята:** 2026-09-22

## Контекст

Находка 2026-09-19 при заведении BS-63, метка major: README бэклога обещает, что в `triage/` поле «Область» не проверяется и заполняется при разборе, а `lint` сразу после `new` красный. `new` пишет строку `- **Область:** [TODO: раздел](../../reference/README.md)`; `lintAreaField` её в `triage/` пропускает, но `lintBacklogTodos` (`lib/lint.js`, `isTodoPlaceholder`) читает значение поля по `TODO_FIELD` и `TODO_VALUE` узнаёт `[TODO…](../triage/…)`. Улика: `node bin/backslop.js new x --title "…"`, затем `node bin/backslop.js lint` → `✖ docs/backlog/triage/BS-63-…md: строка 3: осталась заглушка [TODO]`. Для `minor/` та же строка исключена явно (`areaLine`), для `triage/` — нет.

**Зачем:** карточка, заведённая штатной командой, не проходит гейт проекта до разбора; либо README врёт, либо гейт.

## Что сделать

- Решить, что верно: исключить строку «Области» из гейта заглушек в `triage/` так же, как в `minor/`, либо переписать README и `new`; красная проба на выбранный вариант.

## Разбор triage 2026-09-22 — предмет впятеро больше, развилка за владельцем

Воспроизведено на копии репозитория (исходное дерево не тронуто): базовый `lint` → код 0;
`new bs64-repro --title "…"` → код 0; повторный `lint` → код 1, **ошибок 5** — строки 3, 9, 13, 17,
21. Красна не только «Область»: краснеют три `- [TODO]` из секций «Что сделать», «Не входит»,
«Проверки» и `[TODO: откуда задача…]` из «Контекста».

Поэтому ход из карточки — исключить строку «Область» в `triage/`, как это сделано для `minor/` —
оставит четыре ошибки из пяти и не закроет собственный симптом: карточка, заведённая штатной
командой, останется красной.

Развилка, которую решает владелец: либо гейт заглушек вовсе не смотрит в `triage/` — тогда
переписывается раздел README про «любой markdown-файл `docs/backlog/**`», — либо `new` перестаёт
класть в `triage/` шаблон с заглушками и пишет файл в одну-две строки, как README требует в
разделе «Как вести». Цена низкая в обоих случаях: одно условие в `lib/lint.js` либо один шаблон.
