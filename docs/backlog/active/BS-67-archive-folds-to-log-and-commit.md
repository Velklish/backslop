# BS-67 · Закрытая задача сворачивается в строку журнала, тело уезжает в сообщение коммита

- **Область:** [01. Раскладка](../../reference/01-layout.md), [02. CLI](../../reference/02-cli.md), [03. Гейты lint](../../reference/03-lint.md)
- **Создана:** 2026-09-22
- **Зависимости:** нет
- **Взята:** 2026-09-22

## Контекст

Архив растёт линейно от числа закрытий и вытесняет живые доки из выдачи поиска. Замер 2026-09-22 по трём репозиториям на backslop: ati-agents — 772 каталога, 1544 файла, 5,35 МБ текста против 101 живого `.md`; promptobus — 310 / 619 / 2,18 МБ против 69; backslop — 70 / 139 / 518 КБ. Доля архива среди файлов с совпадением при грепе по `docs/` в ati-agents: `doctor` — 317 из 360 (88 %), `promptobus` — 672 из 724 (92 %), `worktree` — 263 из 292 (90 %), `мутационн` — 103 из 112 (91 %). Темп: 185 закрытий в 2026-08, 311 в неполном 2026-09.

Диск и механика при этом не болят: `lint` на 772 каталогах — 0,10 s, `size-pack` ati-agents — 25,24 MiB. Болит findability, и прецедент уже записан: [ADR-012](../../adr/adr-012-owned-outputs-gitignore.md) фиксирует случай, где единственное упоминание gitignore во всём репозитории лежало в закрытой карточке — то есть в отчёте о прошлой работе, а не в действующем правиле. Код уже относится к архиву как к мёртвому слою: `lib/lint.js:489` выводит `docs/archive/` из проверки цитат, гейты полей и заглушек его пропускают.

Аудит «что живёт только в архиве» (backtick-идентификаторы, пороги 3/5/8 архивных файлов на репозиторий): backslop — 14 кандидатов из 220, promptobus — 38 из 529, ati-agents — 11 из 591. После ручного разбора содержательных нет: имена прогонов и track'ов, хэши коммитов, пути тестовых файлов, старые пины CLI и одна константа, удалённая вместе с фичей (`BUS_HOOK_MATCHER`, снята в PB-173). Уникального знания архив не держит, и сворачивание не требует предварительного дозаполнения справочника.

Конструкцию определяет ограничение git: тело карточки, заведённой и закрытой внутри одного схлопнутого коммита, в истории не существует ни в одном снимке. В backslop таких 7 из 69 — `BS-4.1`, `BS-5`, `BS-6`, `BS-7`, `BS-60`, `BS-61`, `BS-62`; у остальных 62 тело лежит в истории под `docs/backlog/**`. `result.md` рождается на приёмке и при сворачивании в дерево не попадёт вовсе. Поэтому хранилище тела — сообщение коммита закрытия, а не снимок дерева: текст сообщения хранится независимо от того, был ли файл в родительском снимке.

## Что сделать

- `docs/archive/LOG.md` — журнал закрытых: строка на задачу с номером, slug, заголовком, датой закрытия, исходом (выполнена / отклонена / слита в M) и коммитом закрытия. Он становится источником номеров закрытых задач вместо каталогов.
- `archive N` сворачивает вместо переезда: требует непустой `result.md`, печатает заготовку commit message с полными `task.md` и `result.md`, удаляет каталог задачи, дописывает строку в `LOG.md`, переписывает входящие ссылки на якорь строки. Отказы: `result.md` пуст или остался заглушкой.
- `show N` — по строке журнала найти коммит и напечатать `git show`.
- `scanTasks` и `foreignTaskIds` читают оба источника — строки `LOG.md` и каталоги `archive/*/`: репозиторий со свёрнутыми и несвёрнутыми записями остаётся рабочим сколько угодно долго.
- `fold [--older-than <дата>] [--dry-run]` — сворачивание накопленного: по каждому телу `git cat-file` до удаления, отказ, если тела в истории нет, перепись входящих ссылок. Цена на сегодня: 85 входящих ссылок в ati-agents, 31 в promptobus, 15 здесь.
- `lint`: гейт строки журнала на каждый упомянутый закрытый номер; гейт архива остаётся для несвёрнутых каталогов.
- `MIGRATIONS` со `since`: заводит `LOG.md`, не удаляет ничего — апгрейд не сносит накопленное молча.
- Доки тем же ходом: `reference/01-layout.md`, `02-cli.md`, `03-lint.md`, `docs/archive/README.md` в паре с `templates/docs/archive/README.md`, английский близнец в `templates/en/`, `CHANGELOG.md`. Контракт меняется — новый ADR: журнал работ живёт в git, дерево держит только живое.

## Не входит

- Сворачивание архивов потребителей — ati-agents (772) и promptobus (310) сворачиваются своими задачами в своих репозиториях после подъёма пина.
- `unfold N` — возврат свёрнутой задачи в статус: пока руками через `git show`, как любой возврат из архива.
- Ретеншен по возрасту как режим по умолчанию: `--older-than` остаётся флагом владельца, автоматического порога нет.

## Проверки

- Сворачивание: каталога задачи нет, строка в `LOG.md` на месте, входящая ссылка из соседнего дока переписана, заготовка сообщения содержит оба файла целиком (тест).
- Отказы кодом 1 с текстом причины: пустой `result.md`, заглушка в нём, отсутствие тела в истории при `fold` (тест).
- Номера: `new --parent` на свёрнутой задаче не выдаёт занятый номер, `lint` не краснеет на упоминании свёрнутого номера (тест).
- Гибрид: проект со свёрнутыми и несвёрнутыми записями проходит `lint` зелёным (тест).
- Красная проба гейта журнала в `test/lint.test.mjs`.
- `node bin/backslop.js gates` зелёный, счёт тестов до и после назван в `result.md`.
