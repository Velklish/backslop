# BS-21 · ADR-004 разрешает выводить источник релизов из npm-формы, ADR-007 и код это запрещают — статус ADR-004 остался Accepted без пометки о замене

- **Область:** `docs/adr/adr-004-version-pin-upgrade.md`, `docs/adr/adr-007-npm-pin.md`, `docs/README.md`, `lib/config.js`
- **Создана:** 2026-09-06
- **Зависимости:** нет
- **Взята:** 2026-09-09

## Контекст

docs/adr/adr-004-version-pin-upgrade.md:33 (Consequences) — «Форма пина стабильна: `npx github:owner/repo#vX.Y.Z`; публикация в npm меняет только её на `npx backslop@X.Y.Z`, источник релизов тогда объявляется полем `source` **или выводится из новой формы**.» docs/adr/adr-007-npm-pin.md:18 (Decision) отменяет вторую половину прямо: «Источник тегов из npm-формы не выводится: его задаёт поле `source`.»

Код реализует версию ADR-007, не ADR-004: комментарий `lib/config.js:37` — «из npm-формы не выводится: его явно задаёт поле source»; `parseCli` (lib/config.js:42-56) возвращает `repoUrl` только для github-формы (строка 53: `repoUrl: github ? … : null`) — для npm-формы всегда `null`, вывода из формы нет нигде в коде. `lib/upgrade.js:58-62` при отсутствии `source` и npm-форме отказывает с явным сообщением «обновлять нечего».

Статус: заголовок adr-004 — «**Status:** Accepted» (строка 3), строка таблицы docs/README.md:15 — тоже «Accepted», без пометки о частичной замене. Прецедент формы уже есть в этом же файле: adr-006 несёт «Status: Superseded in part by `ADR-008` (legacy-default)» (adr-006:3), и та же формулировка продублирована в docs/README.md:17. Между ADR-004 и ADR-007 такой связи нет ни в одну сторону.

Принцип самого проекта — docs/README.md:24 — «Принятое решение не правится — заменяется. Новое решение по тому же вопросу — новый ADR; в заменяемом остаётся пометка «заменён ADR-NNN».» Гейт 8 (`lintAdrIndex`, lib/lint.js:238-256) проверяет только наличие строки-ссылки в таблице, не текст Status — расхождение не ловится ничем.

## Что сделать

- В шапку docs/adr/adr-004-version-pin-upgrade.md добавить строку статуса по форме ADR-006: «**Status:** Superseded in part by `ADR-007` (источник релизов при npm-форме)».
- Ту же формулировку — в ячейку docs/README.md:15 (как уже сделано для adr-006 в строке 17).
- В bullet 33 (Consequences) убрать отвергнутую альтернативу «или выводится из новой формы», оставить «источник релизов объявляется полем `source` (см. ADR-007)».

## Не входит

- Код: `lib/config.js`/`lib/upgrade.js` уже реализуют правило ADR-007, эта задача правит только бумажный след.
- Гейт `lint`, сверяющий текст Status с графом замен ADR, — отдельная и существенно более крупная задача (разбор свободного текста статусов); здесь — только конкретное расхождение.

- `node bin/backslop.js lint` зелёный (гейт 8 проверяет только наличие строки, формулировка Status на него не влияет).
