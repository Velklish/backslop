# BS-58 · Шаблон AGENTS.md требует мутационную пробу, не называя инструмента

- **Область:** `templates/agents-section.md`, [02. CLI](../../reference/02-cli.md) § init
- **Создана:** 2026-09-16, остаток PB-190 из promptobus
- **Зависимости:** нет
- **Взята:** 2026-09-16

## Контекст

Гейт 4 сгенерированного раздела требует пробы, но не называет команды, которой она гоняется:

<!-- quote:../../../templates/agents-section.md -->
4. **Гейты до отчёта.** `{{cli}} gates` зелёный: команды из `gates` в `backslop.json`, код каждой и счёт «гейтов N, зелёных M». Правку теста проверяй мутационной пробой: сначала коммит, потом проба.
<!-- /quote -->

Названа **обязанность**, а не **инструмент**. Агент, читающий раздел как правила, обязанность видит и собирает пробу руками — своим `sed` по файлу, своим восстановлением, своим определением того, что считать красным.

Замерено в promptobus (`PB-190`, архив): у репозитория проба есть — `npm run probe`, `scripts/mutation-probe.mjs`, — и документирована она на уровень ниже, в руководстве для участника, которое протокол загрузки правил читать не заставляет. Участник её не нашёл и сделал свою. Починка там местная: репозиторий дописал раздел «Mutation probes» **вне** сгенерированного блока, и он переживает `init`. Каждый следующий репозиторий, засеянный этим шаблоном, повторит ту же работу.

Своей пробы у backslop нет и быть не должно: команда у каждого репозитория своя. Предмет карточки — как шаблон спрашивает про неё, а не какой она должна быть.

## Что сделать

- Решить форму: поле в `backslop.json` (по образцу `gates` и `cli`), из которого шаблон подставляет команду пробы, — либо строка в шаблоне, отсылающая к местному разделу, когда поля нет.
- Шаблон называет инструмент, когда он объявлен, и не называет обязанности без инструмента, когда не объявлен: правило, которое нечем исполнить, дороже отсутствия правила.
- `init` в репозитории без объявленной пробы не должен молча выкидывать требование — решение о тексте принять вместе с формой поля.

## Не входит

- Сама реализация пробы в чужих репозиториях: `npm run probe` promptobus остаётся его файлом.
- Ретроактивная правка уже засеянных репозиториев: раздел вне генерируемого блока принадлежит им.

## Проверки

- Прогон `init` на стенде с объявленной пробой и без неё: в первом случае команда стоит в тексте, во втором требования без инструмента в тексте нет.
- Мутационная проба на проверке шаблона: подмена подставляемой команды краснеет.
