# ADR-029: Находка в minor/ заводится только с уликой

**Status:** Accepted
**Date:** 2026-09-22
**Deciders:** Velklish

## Context

[ADR-022](adr-022-cost-decides-finding-fate.md) завёл каталог `minor/` и правило: `minor` и гипотеза
уезжают туда командой `new <slug> --parent N[.M] --minor` и ждут пачки, а не разбора. Раздел «Улика»
команда печатала заглушкой `[TODO: путь к файлу или команда с выводом]` — той же, что у находки
в `triage/`.

В `triage/` заглушка безобидна: [BS-64](../archive/LOG.md) снял с этого каталога гейт заглушек
именно потому, что запись там достраивают при разборе. В `minor/` разбора нет по замыслу, и гейт
заглушек с него не снимали. Замер на экспорте дерева `a74dc1a` (`git archive`, вне репозитория),
команды подряд:

```
node bin/backslop.js lint                                        → код 0, «lint: ошибок нет»
node bin/backslop.js new minor-evidence-probe --parent 64 --minor → код 0
node bin/backslop.js lint                                        → код 1
✖ docs/backlog/minor/BS-64.1-minor-evidence-probe.md: строка 11: осталась заглушка [TODO]
```

Штатная команда инструмента оставляла проект с красным гейтом. Автор находки либо правил файл руками
сразу после команды, либо нёс красноту в отчёт.

## Варианты

**Решение 1: где чинить.**

- **1A — исключить строку «Улика» в `minor/` из гейта заглушек**, как уже исключена «Область».
  Точечно и дёшево. Цена: разрешает ровно то, что запрещает правило трекера, — запись без улики.
- **1B — снять гейт заглушек с `minor/` целиком**, как [BS-64] снял его с `triage/`. Шире и
  согласуется с тем, что `minor/` ждёт пачки. Цена: та же — карточка без улики становится законной,
  а разбирать её при резке пачки будет уже не автор и по памяти.
- **1C — чинить команду: требовать улику флагом и отказывать без неё.** Цена: ломает сигнатуру
  `--minor`, которую называет 18 живых файлов прозы обоих языков, включая цитируемый блок
  `<!-- backslop:start -->` и оба скилла.

**Решение 2: считать ли гипотезу исключением.**

- **2A — гипотеза заводится без улики:** непроверенное утверждение улики не имеет по определению.
- **2B — гипотеза несёт улику наравне с проверенной находкой**, только формулировкой предположения.

## Decision

Выбраны **1C** и **2B**.

Гейт прав, а команда — нет. Правило трекера говорит «`minor` и любая находка без проверенной улики —
`--minor`», и запись без улики бессмысленна по самому правилу: через неделю её нечем проверить,
а автора рядом уже нет. Дефект в команде, которая молча рождает неполную карточку и оставляет
проект с красным гейтом.

`new <slug> --parent N[.M] --minor` требует `--evidence "<текст>"` и отказывает без него **до любой
записи на диск** — до `scanTasks`, до `writeText`, до перенумерации очереди. Пустая и пробельная
улика равны отсутствующей. Текст отказа называет, чем улика бывает: путь со строкой, команда
с выводом и кодом возврата, замер числом.

Гипотеза исключением не служит (2B). «Не проверено» — это не право пропустить улику, а обязанность
написать её предположением, и текст отказа учит ровно этому: `--evidence "предположительно …"`.
Исключение для `--hypothesis` вернуло бы пустую карточку через боковую дверь.

В `triage/` заглушка остаётся: там находку достраивают при разборе, и гейт заглушек с этого каталога
уже снят. Асимметрия намеренная — она повторяет разницу между каталогом с разбором и каталогом без него.

Флаг `--evidence` вне `--minor` — отказ, одной проверкой с `--cost` и `--hypothesis`.

## Consequences

- Карточка, **заведённая `new`**, с рождения проходит `lint`: заглушке `[TODO]` в разделе «Улика»
  взяться неоткуда. Гейт заглушек не тронут — ни его состав, ни число гейтов `lint` не менялись.
- Вторая дверь в `minor/` этим решением не закрыта: `mv N.k minor` переносит файл, не меняя его
  формы, и находка из `triage/`, собранная по `task.md`, приносит в каталог, который судит по
  `minor.md`, четыре заглушки — улику и три раздела постановки. Замер на временном проекте:
  чистый проект — код 0, находка в `triage/` — код 0, она же после `mv 1.1 minor` — код 1,
  ошибок 4. Ход по этой двери — за владельцем, карточка заведена.
- Сигнатура `--minor` переписана в 18 живых файлах обоих языков — 19 мест, потому что справка
  обеих половин живёт в одном `bin/backslop.js`: эта справка, оба README,
  `01-layout.md` и `02-cli.md`, `GLOSSARY.md`, три копии правил бэклога, три копии блока
  `<!-- backslop:start -->`, оба брифа и оба скилла в обеих языковых раскладках. Потребители,
  перерисовывающие блок, поднимут новую редакцию своим `upgrade`.
- Строка ADR-022 про `--minor` без улики этим решением заменена; сам ADR-022 остаётся снимком
  своего момента и не правится.
- Цена ложится на автора находки: улику надо сформулировать в момент команды, а не «потом».
  Это и есть предмет решения — «потом» в `minor/` не наступает.
- Находка `major` вне области по-прежнему заводится `new <slug> --parent N` с заглушкой улики
  в `triage/`, и флаг `--evidence` там отвергается. Красного гейта это не даёт; сводить ли две
  ветки к одной форме — отдельное решение владельца.
