# ADR-003: Node без зависимостей, доставка `npx github:`

**Status:** Accepted
**Date:** 2026-09-03
**Deciders:** Velklish

## Context

Инструмент должен разворачивать процесс в любой проект одной командой на машине, где стоит агент, и не тянуть за собой зависимости. Код переписи ссылок, обхода markdown и гейтов уже существовал на JavaScript вместе с тестами.

## Варианты

- **Node ≥ 20, только стандартная библиотека.** Доставка — `npx github:Velklish/backslop <команда>`: нужны Node и git, публикация в реестр не требуется. Код и тесты переезжают как есть.
- **Python, только стандартная библиотека.** Доставка — `uvx --from git+… backslop` или `pipx`: нужен предустановленный `uv` или `pipx`; голый `python3` на macOS бывает старым, на Windows часто заглушка Store. Код и тесты пишутся заново.

## Decision

Node без зависимостей. Node уже есть у всех, кто ставит агента из npm, и в окружении автора; `npx github:` даёт одну команду без предустановки. Публикация в npm остаётся отдельной задачей и меняет только умолчание поля `cli`.

## Consequences

- Ни `dependencies`, ни шага сборки: `npx github:` берёт репозиторий как есть; `package.json` объявляет только `bin`, `files` и `engines`.
- На машине нужен `git`; первый запуск клонирует репозиторий, дальше работает кэш npx.
- Внутри проекта команда называется через поле `cli` в `backslop.json`, чтобы скиллы и блок `AGENTS.md` не зависели от способа установки: `npx github:…`, глобальная установка или `node bin/backslop.js` в самом репозитории инструмента.
