# ADR-036: Вторая дверь в minor/ — `mv N minor` — требует улику, `lint` требует раздел «Улика»

**Status:** Accepted
**Date:** 2026-09-24
**Deciders:** Velklish — решение по развилке записано в карточке пачки [BS-79](../archive/LOG.md#bs-79) (2026-09-24); текст ADR написан worker'ом bs79 захода bs-0924-t20260924-115051 и владельцем не вычитан

## Context

[ADR-029](adr-029-minor-finding-requires-evidence.md) закрыл первую дверь в `minor/`: `new --minor`
без `--evidence` отказывает до записи. Вторую дверь он оставил открытой и назвал это в Consequences.
Два замера этой двери:

- [BS-64.2](../archive/LOG.md#bs-64.2): временный проект, `new finding --parent 1` → `lint` код 0;
  `mv 1.1 minor` → `lint` код 1, ошибок 4. Находка из `triage/` собрана по `task.md` и приносит
  в `minor/` заглушку улики и три заглушки разделов постановки — «Что сделать», «Не входит», «Проверки».
- [BS-64.3](../archive/LOG.md#bs-64.3): замер worker'а BL-709 (backslop v0.10.0) — `mv 704 minor` → код 0,
  раздела «Улика» нет (`grep -c '^## Улика'` → 0), `lint` → код 0. Карточка без улики лежит
  в `minor/`, и гейт молчит: правило улики держится только дисциплиной.

## Варианты

- **А — переформовывать карточку при переезде целиком по шаблону `minor.md`.** Теряет текст,
  который автор уже написал.
- **Б — требовать улику у `mv N minor`**, как у `new --minor`: отказ до переноса без неё.
  Отказ ложится на approver'а, который находку не писал.
- **В — снять гейт заглушек с `minor/`**, как [BS-64](../archive/LOG.md#bs-64) снял его с `triage/`. Запись без улики
  снова становится законной — отменяет предмет ADR-029.

## Decision

Выбран **Б с добавкой** (решение владельца 2026-09-24).

`mv N[.k] minor` требует улику: раздел «Улика» (`Evidence`) с текстом и без заглушки `[TODO…]`
либо флаг `--evidence "…"`. Проверка идёт по всему пакету до первого переноса; без улики — отказ,
который называет номера и учит тем же трём формам улики, что `new --minor`. Флаг — только с одним
номером: улика у каждой записи своя.

Карточка формы `task.md` при переезде переформовывается без потери текста:

- разделы постановки — «Контекст», «Что сделать», «Не входит», «Проверки» — из одних заглушек
  снимаются целиком; в разделах с текстом снимаются только строки-заглушки;
- «Контекст» с текстом становится «Уликой», когда раздела «Улика» нет;
- `--evidence` пишет строку `Улика: …` (`Evidence: …` в EN-проекте), как `new --minor`: на место
  первой заглушки раздела, иначе в его конец, иначе новым разделом.

Подсказка `new` о блоке цитаты в карточке находки заглушкой не является и остаётся: это текст,
а не `[TODO]`.

`lint` (гейт 4) в `minor/` требует раздел «Улика»: нет его, он пуст — ошибка; заглушка в нём —
ошибка. Дверь закрыта с той же стороны, что у `new --minor`: не только команда, но и гейт.

## Consequences

- `mv N minor` без улики больше не проходит молча: approver, переводящий гипотезу из `triage/`,
  формулирует улику флагом — «не проверено» пишется предположением, `--evidence "предположительно …"`.
- Запись, положенная в `minor/` руками без «Улики», красит `lint`; до этого решения гейт молчал.
  У потребителей такие записи всплывут после `upgrade` — перегенерации их карточек это решение
  не делает.
- `lib/tasks.js` знает разделы «Контекст», «Проверки» и «Улика» по именам обоих языков.
- ADR-029 остаётся снимком своего момента: его пункт про открытую вторую дверь заменён этим решением.
