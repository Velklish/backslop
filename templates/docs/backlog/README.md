# Backlog

Операционный трекер {{project}}: **одна задача — один файл**, **статус — каталог**, в котором файл лежит. Списка задач здесь нет — его печатает `{{cli}} status`. Куда движется проект в целом — [ROADMAP.md](../ROADMAP.md); закрытые задачи — [архив](../archive/README.md).

## Каталоги

| Каталог | Что там | Как попадает |
|---|---|---|
| `triage/` | Неразобранное: идеи и находки до разбора. Файл и есть запись | `{{cli}} new <slug> --title "…"`; находка — `{{cli}} new <slug> --parent N` |
| `queue/` | Очередь; приоритет — поле «Порядок»: целое, шаг 10, меньше — раньше | `{{cli}} new <slug> --queue [--top]`, `{{cli}} mv N queue [--top \| --after M]` |
| `active/` | В работе; поле «Взята» — дата взятия | `{{cli}} mv N active` — тот, кто держит очередь |
| `deferred/` | Отложено; раздел «Отложено» — причина и условие возврата | `{{cli}} mv N deferred`, затем заполнить раздел |
| [`../archive/`](../archive/README.md) | Закрыто: `task.md` + `result.md` | `{{cli}} archive N`, затем дописать `result.md` |

## Как вести

- Идея пришла — файл в одну-две строки в `triage/`, без разбора и оформления. Разбор — отдельным заходом.
- Находка с ревью, от worker'а или из живого прогона, которую этот заход не закроет, — сразу файл с `--parent N`: она получает номер `N.k` и не требует координации с соседями. В чате она потеряется. Текущую задачу не дублируй.
- Проверяемый факт в записи — число, «покрыто тестом», «печатают три команды» — сопровождай уликой: командой или файлом со строкой, которыми он получен. Не проверил — пиши как предположение. Постановка с неверным фактом даёт исполнителю неверные границы, и правдой её делает красный тест посреди чужой работы.
- **Номер сквозной**, после закрытия не переиспользуется; считает его `{{cli}} new` по каталогам текущего дерева, других worktree репозитория и всех локальных веток — worker в worktree и оркестратор в основном дереве получают разные номера, чужой занятый номер команда называет. Столкновение остаётся возможным с клоном или неподтянутой удалённой веткой — его ловит `{{cli}} lint` при слиянии, и проигравший перезаводит файл.
- **Статус = каталог** — единственное место, где он живёт. Файл задачи держит постановку, область (ссылка на раздел [reference/](../reference/README.md)), даты и текущее состояние.
- **Приоритет = поле «Порядок»** в `queue/`. Переставить — `{{cli}} mv N queue --top` или `--after M`, в том числе для задачи, уже стоящей в очереди: файл остаётся, меняется число. Один «Порядок» у двух файлов — ошибка `lint`.
- **Закрытие** — выполнена, отклонена или слита — `{{cli}} archive N`: файл уезжает в архив как `task.md`, рядом ложится `result.md` с датой. Исход и результат дописывает approver; пока в `result.md` есть `[TODO]`, `lint` красный.
- Отложенная получает раздел «Отложено» с причиной и условием возврата; без них `lint` красный.
- Задача, выросшая в архитектурное решение, уходит в [ADR](../README.md); в файле остаётся ссылка.
- Гейты проекта — поле `gates` в `backslop.json`; `{{cli}} lint` входит в них.

## Такт разбора triage

Точек разбора две, и одна другую не отменяет:

- **перед заходом worker'ами — целиком**, до резки очереди на track'и: записи прошлых заходов относятся ровно к тем подсистемам, которые режутся сейчас, и уезжают в track'и этого захода бесплатно;
- **после каждой закрытой задачи** — по записям, накопившимся за неё, а не когда накопится.

Запись, пролежавшая несколько заходов, теряет контекст: автор находки — сессия, которой уже нет.

Агент решает сам и не спрашивает:

- слить дубль в существующую задачу, уточнить формулировку;
- поставить запись в очередь и выбрать ей место;
- отложить с условием возврата.

Проверяемое утверждение записи разбор проверяет уликой до постановки в очередь; непроверенное переписывается предположением. К владельцу агент идёт **только за отказом**: находка, выброшенная без спроса, второй раз никем не будет найдена. Порядок работ — работа агента; владелец ставит цели и разворачивает приоритет, когда ему нужно иначе.

Разбор закончен, когда у каждой записи `triage/` есть ход: слита, переехала в другой каталог или закрыта решением владельца.
