## Сквозные принципы

1. **В каталоге ADR — только действующие решения.** Новое решение по уже решённому вопросу переписывает ADR этого вопроса на месте: тот же номер, обоснование, которое ещё держится, последствия перемены. ADR, который больше ничего не решает, удаляется; его историю хранит git. Цепочка ADR по одному вопросу сворачивается в её старший номер.
2. **Улика сильнее ощущения.** Число, путь к файлу или вывод команды — в постановке, результате и ADR; непроверенное пишется как предположение.

Новый ADR — `{{cli}} adr <slug>` **и строка со ссылкой на него в таблицу выше**: без ссылки `{{cli}} lint` красный.
