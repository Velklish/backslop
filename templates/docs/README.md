## Сквозные принципы

1. **Принятое решение не правится — заменяется.** Новое решение по тому же вопросу — новый ADR; в заменяемом остаётся пометка «заменён ADR-NNN».
2. **Улика сильнее ощущения.** Число, путь к файлу или вывод команды — в постановке, результате и ADR; непроверенное пишется как предположение.

Новый ADR — `{{cli}} adr <slug>` **и строка в таблицу выше**: без строки `{{cli}} lint` красный.
