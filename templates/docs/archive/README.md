# Архив закрытых задач

До свёртки закрытая задача — каталог `{{prefix}}-<номер>-<slug>/` с двумя файлами: `task.md` — постановка (что и зачем делали, когда появилась) и `result.md` — результат с датой и исходом. Выполненные, отклонённые и слитые лежат вместе; исход назван в `result.md`. После свёртки у неё есть строка в [LOG.md](LOG.md), а каталога в дереве нет.

Живые задачи — в [backlog/](../backlog/README.md). Номера сквозные и не переиспользуются; пропуск номера в архиве означает, что задача ещё жива или так и не была заведена.

Пачка minor-записей — тот же каталог с подкаталогом `minor/`: записи, закрытые `{{cli}} archive N.k --into M`, лежат там как есть, без своего `result.md`; исход по каждой называет `result.md` пачки.

Переезд делает `{{cli}} archive N`: он же переписывает ссылки на задачу по всему репозиторию, кладёт заготовку `result.md` и печатает файлы доков, которых коснулся ход задачи, — заготовку строки «какие доки поправлены»; `--range <база>..HEAD` расширяет список коммитами диапазона. Пока в `result.md` осталась заглушка `[TODO` вне кода, `lint` красный; форма заглушки, показанная в код-спане, заглушкой не считается.

Закрытая задача сворачивается в строку журнала [LOG.md](LOG.md): `{{cli}} fold N` удаляет каталог, дописывает строку и переводит входящие ссылки на её якорь — `LOG.md#<номер в нижнем регистре>`. Постановка и результат целиком уезжают в сообщение коммита свёртки: команда печатает его заготовку в stdout. Коммит с ней обязателен, когда в поле коммита строки стоит `—`: в дереве тела уже нет, а в истории ещё нет. Строка назвала ревизию — тело лежит в ней, и заготовка не обязательна, пока ревизия остаётся в истории; какой из двух случаев, `fold N` говорит на stderr. Достаёт тело `{{cli}} show N`.

Накопленный архив сворачивается тем же `{{cli}} fold` без номера: там тело берётся не из сообщения, а из истории, и строка журнала называет ревизию. Тело, которого нет в истории, уходит вместе с каталогом с предупреждением, если только `{{cli}} fold --embed-missing` не положит его в заготовку — тогда заготовку нужно закоммитить. Строка журнала такой задачи несёт `—` в поле коммита. `--older-than <дата>` сворачивает только закрытое раньше названной даты.

Обе формы записи законны и живут рядом сколько угодно долго: каталог — это задача, закрытая и ещё не свёрнутая. Свёртка обязательной не является.

Файл принадлежит backslop: обновление (`{{cli}} upgrade`, шаг `migrate`) перерисовывает его из шаблона новой версии, и местная правка здесь до следующего обновления не доживёт.
