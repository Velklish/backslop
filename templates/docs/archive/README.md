# Архив закрытых задач

Каждая закрытая задача — каталог `{{prefix}}-<номер>-<slug>/` с двумя файлами: `task.md` — постановка (что и зачем делали, когда появилась) и `result.md` — результат с датой и исходом. Выполненные, отклонённые и слитые лежат вместе; исход назван в `result.md`.

Живые задачи — в [backlog/](../backlog/README.md). Номера сквозные и не переиспользуются; пропуск номера в архиве означает, что задача ещё жива или так и не была заведена.

Переезд делает `{{cli}} archive N`: он же переписывает ссылки на задачу по всему репозиторию, кладёт заготовку `result.md` и печатает файлы доков, которых коснулся ход задачи, — заготовку строки «какие доки поправлены».
