# Замеры во время захода

Читается из скилла `backslop-batch`, когда число из захода уедет в отчёт, постановку или бриф.

Настенные часы при живом заходе меряют соседей, а не предмет: worker'ы и их гейты делят ядра одной машины, и цифра плавает в разы. Чем мерить вместо часов: CPU процесса (user+sys) — для «стало быстрее или медленнее»; число операций — прогонов, файлов, запросов; арифметика по единичной стоимости, снятой на тихой машине. Часы законны, когда машина пуста или замер объявлен грубым прямо в тексте.

**Код возврата смотри у самой команды, а не у пайпа**: `grep … | wc -l` на упавшем грепе печатает `0` кодом `0`, и отказ инструмента читается как «вхождений нет». Того же класса `npm test | tail`. Ноль в замере проверяй вторым способом.

**Неполный ответ выглядит так же уверенно, как полный.** `\s` в `git grep -E` непереносим: на macOS он молча ничего не находит. Пиши POSIX-классы, например `[[:space:]]`. Класс символов, выписанный под конкретные имена, пропускает соседа с цифрой; проверка литерала glob'ом сверяет существование чего-то с таким префиксом, а не то, что записано. Проверяй тот литерал, который записал.

**Считая вызовы, считай вызовы ровно того, что называет проверка, с фильтром по аргументам:** вызовы `git` — не вызовы `git merge`. **Грепу текст плоский:** «нашёл в комментарии» — гипотеза, пока области языка не разобраны.

**Гейт на дереве, не равном коммиту побайтно, ничего не доказывает про коммит.** Стенд — контейнер, клон, копия — собирается из всего дерева; признак равенства — `diff -r` пуст или `git status` в самом стенде чист. Для гейтов проекта — `{{cli}} gates --require-clean`.

`--measurements` несёт в бриф только краткую сводку из трёх пунктов этих правил; любое другое правило из этого файла попадает в бриф руками, например через `--handover`. Этот файл читает только оркестратор.
