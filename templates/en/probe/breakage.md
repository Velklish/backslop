A mutation probe is deliberate breakage: break the code and make sure the test fails. **The commit comes first:** `git checkout <file>` removes all uncommitted work, not just one mutation. If the probe remains green, first ask whether the code path is live: a check that cannot be broken is dead code, not a coverage gap. If the path is live and the probe is green, the check input does not reach the property it claims to verify; fix the input, not the gate.
